这道题是一个很经典的 **Kruskal + Matrix-Tree 定理（矩阵树定理）** 计数问题。

难点有两个：

1. 同一权值的边在 Kruskal 中可以有多种选择，需要统计这些选择中有多少种能构成 MST。
2. 模数 `p` **不保证是质数**，所以计算行列式时不能直接使用“模意义下高斯消元 + 逆元”。

---

## 1. Kruskal 为什么可以分权值统计？

Kruskal 按边权从小到大处理。

假设现在处理所有权值为 `w` 的边。

在处理它们之前，我们已经把所有 `< w` 的边处理完了。此时并查集中的每个连通块可以看成一个“超级点”。

对于权值为 `w` 的边：

- 如果一条边两个端点已经属于同一个并查集连通块，那么它绝对不可能被当前阶段选入 MST；
- 否则，它就是两个“超级点”之间的一条边。

于是，同一权值的所有候选边形成一个新的 **缩点图**。

在这个缩点图的每一个连通块中，如果有 `k` 个超级点，那么 Kruskal 必须选：

\[
k-1
\]

条当前权值的边，把它们连接起来。

也就是说：

> 必须从这个缩点图中选择一棵生成树。

所以问题变成了：

> 这个缩点图有多少棵生成树？

这正好可以用 **Matrix-Tree 定理**。

---

# 2. Matrix-Tree 定理

对于一个无向图，构造 Laplacian 矩阵 `L`：

\[
L_{ii}=\deg(i)
\]

如果 `i,j` 之间有边：

\[
L_{ij}=-cnt(i,j)
\]

这里要特别注意 `cnt(i,j)`。

原图虽然保证没有重边，但是经过并查集缩点以后，**可能产生重边**。

例如：

```text
A 中有 a1,a2
B 中有 b1,b2

a1-b1
a2-b2
```

缩点后就是超级点 A、B 之间两条边。

这两条边代表两种不同 MST，因此必须都统计进去。

根据 Matrix-Tree 定理：

> 删除 Laplacian 任意一行和一列，剩下矩阵的行列式绝对值，就是生成树数量。

例如一个连通块有 `k` 个点，只需要求一个：

\[
(k-1)\times(k-1)
\]

矩阵的行列式。

# 3. 为什么不同连通块可以直接相乘？

对于当前权值 `w`，缩点图可能是：

```text
component 1
component 2
component 3
...
```

每个连通块必须独立选择一棵生成树。

假设生成树数量分别为：

\[
T_1,T_2,\dots,T_s
\]

那么当前权值产生的方案数就是：

\[
T_1T_2\cdots T_s
\]

不同权值之间也相互独立，因此最终：

\[
Ans=\prod_{\text{所有权值}}
\prod_{\text{当前缩点图连通块}} T
\]

---

# 4. 一个非常重要的细节：处理完当前权值后应该怎么 union？

不是只 union 某一种生成树里的边。

而是：

> 把当前权值的所有候选边全部 union。

为什么？

因为到了更大的权值时，我们只关心：

> 使用权值 `<= w` 的边后，哪些点必然已经属于同一个 Kruskal 连通块。

同一个缩点图连通块无论具体选哪棵生成树，最终都会被连接起来。

所以直接：

```cpp
for (当前权值的所有边)
    dsu.unite(u, v);
```

即可。

这也是这类题最重要的 Kruskal 计数技巧之一。

# 5. 最大的坑：p 不一定是质数

题目只给：

\[
1\le p\le 10^9
\]

比如：

```text
p = 12
```

样例就是如此。

因此不能写通常的：

```cpp
factor = a[j][i] * inv(a[i][i]) % p;
```

因为 `a[i][i]` 在模 `p` 下可能根本没有逆元。

例如模 12：

\[
6^{-1}
\]

不存在。

所以要使用一种 **不需要除法逆元的行列式求法**。

---

# 6. 任意模数下求行列式：欧几里得消元

我们利用两个基本性质：

### 行变换 1

\[
R_i\leftarrow R_i-qR_j
\]

行列式不变。

### 行变换 2

交换两行：

\[
R_i\leftrightarrow R_j
\]

行列式变号。

因此对于第 `i` 列，可以不断做：

```cpp
q = a[i][i] / a[j][i];

row[i] -= q * row[j];
swap(row[i], row[j]);
```

这实际上就是欧几里得算法。

比如当前：

```text
a[i][i] = 17
a[j][i] = 5
```

那么：

```text
17 - 3 * 5 = 2
```

交换之后变成：

```text
5
2
```

继续：

```text
5 - 2 * 2 = 1
```

最终下面的元素变成 `0`。

整个过程：

- 不需要求逆元；
- 只进行加减乘；
- 可以直接模任意 `p`；
- 每次交换行记录一次符号变化。

最后矩阵成为上三角：

\[
\det(A)=(-1)^s\prod_i A_{ii}
\]

---

# 7. 整体算法

对于每种权值：

1. 当前全局 DSU 表示所有更小边权已经形成的连通块；
2. 扫描当前权值所有边；
3. 将端点替换成全局 DSU 根；
4. 如果两个根相同，忽略；
5. 否则建立一个临时缩点图；
6. 用临时并查集求这个缩点图的各个连通块；
7. 对每个连通块：
   - 建 Laplacian；
   - Matrix-Tree 求生成树数；
   - 乘入答案；
8. 最后把当前权值的所有原图边加入全局 DSU。

全部边处理结束后，如果整个图还不连通：

```text
没有 MST
```

答案就是 `0`。

# 9. 代码中一个容易看漏的问题：重边

虽然题目说：

> `It is guaranteed that there are no multiple edges`

但这只是**原图**没有重边。

假设处理较小权值后：

```text
1 --- 2

3 --- 4
```

已经分别缩成两个连通块：

```text
A = {1,2}
B = {3,4}
```

当前权值有：

```text
1 -- 3
2 -- 4
```

缩点以后：

```text
A ===== B
   两条边
```

那么这个图有两棵生成树——任选其中一条边。

Laplacian：

\[
L=
\begin{pmatrix}
2 & -2\\
-2&2
\end{pmatrix}
\]

删掉一行一列：

\[
(2)
\]

所以：

\[
T=2
\]

刚好正确。

因此构造 Laplacian 时一定是：

```cpp
lap[x][x]++;
lap[y][y]++;
lap[x][y]--;
lap[y][x]--;
```

**每条原边都要执行一次。**

# 10. 正确性证明

可以分成三个结论。

### 结论一：同权值阶段等价于缩点图生成树计数

处理权值 `w` 前，并查集恰好表示只使用权值 `<w` 的边可以形成的连通块。

将这些连通块缩成点后，对于当前某个缩点图连通块，假设有 `k` 个点。

任何 MST 都必须用当前权值边将这 `k` 个块连接起来。

因为：

- 少于 `k-1` 条无法连通；
- 多于 `k-1` 条会形成环，违背 Kruskal 的最小生成树性质。

因此恰好选择一棵生成树。

所以当前连通块的方案数就是缩点多重图的生成树数量。

---

### 结论二：不同连通块、不同权值的选择相互独立

当前权值缩点图中的不同连通块不存在当前权值边连接，因此选择互不影响。

同时，对于后续更大的边权，只关心当前这些超级点最终是否连通，并不关心内部具体使用哪一棵生成树。

因此可以使用乘法原理：

\[
Ans=\prod T_i
\]

---

### 结论三：Matrix-Tree 正确统计每个缩点图的方案数

根据 Matrix-Tree 定理，一个连通无向多重图的生成树数量等于 Laplacian 任意代数余子式的行列式。

平行边通过 Laplacian 中的边数自然被计入，因此每条不同原边对应的 MST 都会被正确区分。

综上，算法得到的正是 MST 总数。

---

# 11. 复杂度

设某个缩点连通块大小为 `k`。

Matrix-Tree 需要求一个 `k-1` 阶行列式。

普通高斯消元是：

\[
O(k^3)
\]

这里使用欧几里得式消元，由于每对元素可能做若干次 Euclid 操作，大致为：

\[
O(k^3\log p)
\]

题目：

\[
n\le100,\quad m\le1000,\quad w\le10
\]

因此完全可以接受。

空间：

\[
O(n^2)
\]

## 核心模板可以记成

这题本质上是 MST 计数的标准套路：

```text
按照边权从小到大处理

对于每组相同权值：
    1. 用之前的 DSU 缩点
    2. 当前权值边组成缩点多重图
    3. 对缩点图每个连通块：
           Matrix-Tree 求生成树数量
           答案相乘
    4. 将这一权值的所有边加入全局 DSU

最后检查原图是否连通
```

尤其要记住两个坑：

> **同权边必须一起处理，不能一条一条 Kruskal。**

以及：

> **`p` 不一定是质数，所以 determinant 不能使用模逆元高斯消元。**
