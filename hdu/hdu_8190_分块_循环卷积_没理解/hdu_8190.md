对上了，这题是一个很典型的 **根号分块 + FFT 的dominance convolution**。

## 1. 按“位置”分块

设块长为 \(B\)。

对于一个需要统计的数对

\[
(i,j),\qquad i<j,
\]

分两种情况：

1. \(i,j\) 在同一个位置块中；
2. \(i,j\) 在不同的位置块中。

第一种直接暴力。

第二种才是关键。

---

## 2. 同块直接暴力

每个块长度至多 \(B\)。

枚举块内所有

\[
i<j,
\]

如果

\[
a_i\ge a_j,
\]

那么：

\[
ans_{a_i-a_j}++.
\]

总复杂度：

\[
O\left(\frac nB B^2\right)=O(nB).
\]

---

# 3. 不同块时，位置关系已经不重要了

设 \(i\) 在块 \(p\)，\(j\) 在块 \(q\)。

如果

\[
p<q,
\]

那么无论块内具体位置是什么，一定有

\[
i<j.
\]

因此对于两个不同块，我们只需要知道：

> 前面那个块里值为 \(x\) 的数有几个，后面那个块里值为 \(y\) 的数有几个。

定义第 \(b\) 个块的值域频次数组

\[
c_b[x]=\#\{i\text{ 在块 }b:a_i=x\}.
\]

对应多项式

\[
F_b(z)=\sum_x c_b[x]z^x.
\]

对于两个块 \(p<q\)，我们要求

\[
x-y=k
\]

的数对数量。

这正是

\[
F_p(z)F_q(z^{-1})
\]

中 \(z^k\) 的系数。

---

# 4. 为什么可以用循环卷积

取 FFT 长度 \(L\)，满足

\[
L>2n.
\]

我们直接在

\[
z^L=1
\]

的意义下计算。

因为：

\[
-(n-1)\le x-y\le n-1,
\]

所以：

- 非负差 \(k\) 落在下标 \(0,1,\dots,n-1\)；
- 负差 \(-k\) 落在 \(L-k\)。

由于 \(L>2n\)，两部分绝不会冲突。

所以最后直接取 FFT 结果的

\[
0,1,\dots,n
\]

位置即可。

这还能省掉普通相关卷积里的 `reverse` 和偏移量。

---

# 5. 更重要：不需要给每对块做 FFT

如果有 \(m=n/B\) 个块，显然不能枚举块对。

对于当前块 \(q\)，所有前面的块贡献为

\[
\left(\sum_{p<q}F_p(z)\right)F_q(z^{-1}).
\]

设

\[
P=\sum_{p<q}\widehat F_p
\]

是前面所有块 FFT 后的和。

因为 \(F_q\) 的系数都是实数，所以

\[
\operatorname{FFT}(F_q(z^{-1}))
=
\overline{\widehat F_q}.
\]

于是频域中直接：

\[
\boxed{
\widehat D
\mathrel{+}=
P\cdot\overline{\widehat F_q}
}
\]

然后：

\[
P\mathrel{+}=\widehat F_q.
\]

所有块处理完以后，**只需要做一次逆 FFT**。

因此不同块部分只需要：

- 每个块一次正 FFT；
- 最后一次逆 FFT。

复杂度：

\[
O\left(\frac nB\cdot L\log L\right).
\]

由于 \(L=O(n)\)，就是

\[
O\left(\frac{n^2\log n}{B}\right).
\]

加上同块暴力：

\[
\boxed{
O\left(nB+\frac{n^2\log n}{B}\right)
}
\]

取

\[
B=\Theta(\sqrt{n\log n})
\]

得到

\[
\boxed{
O(n\sqrt{n\log n})
}
\]

级别。

这就是这题那个“梦限大”的地方。

---

# 6. 还能把两块塞进一次 FFT

这题 \(n=2\times10^5\)，普通“每块一次 FFT”常数还是比较大。

利用经典 FFT 技巧，把相邻两个块的频次数组 \(f,g\) 塞进：

\[
h_x=f_x+i g_x.
\]

一次 FFT 得到 \(H\)。

因为 \(f,g\) 都是实数，

\[
\widehat f_k
=
\frac{H_k+\overline{H_{-k}}}{2},
\]

\[
\widehat g_k
=
\frac{H_k-\overline{H_{-k}}}{2i}.
\]

因此 **一次 FFT 可以得到两个块的频域结果**。

正 FFT 数量又直接减半。

## 8. 用样例理解一下

数组：

\[
[1,1,4,5,1,4].
\]

最终合法数对为：

### \(k=0\)

相等：

- 三个 `1` 产生 \(3\) 对；
- 两个 `4` 产生 \(1\) 对。

所以

\[
ans_0=4.
\]

### \(k=1\)

只有：

\[
5-4=1
\]

对应位置 \((4,6)\)。

所以

\[
ans_1=1.
\]

### \(k=3\)

只有：

\[
a_3-a_5=4-1=3.
\]

所以

\[
ans_3=1.
\]

### \(k=4\)

只有：

\[
a_4-a_5=5-1=4.
\]

所以：

\[
ans_4=1.
\]

得到

```text
4 1 0 1 1 0 0
```

## 9. 这题最核心的一行

真正值得记的是：

\[
\boxed{
\widehat D
=
\sum_q
\left(\sum_{p<q}\widehat F_p\right)
\overline{\widehat F_q}
}
\]

它同时解决了两个麻烦：

- **位置方向 \(i<j\)**：通过块的先后顺序保证；
- **所有差值 \(k\)**：通过相关/FFT 一次得到。

所以这题不是“用 FFT 把整个数组频次卷一下”，而是：

> **位置分块把偏序 \(i<j\) 变成块间的全序，再对块间值域做相关。**

这个思路比单纯记 `根号分治 + FFT` 更重要。
