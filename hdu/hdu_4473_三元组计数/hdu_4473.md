这道题的核心是一个很漂亮的 **三元组计数 + 对称性枚举**。

## 1. 把原问题转成三元组计数

定义

\[
f(x)=\#\{(a,b):a,b>0,\ ab\mid x\}.
\]

要求

\[
S(n)=\sum_{x=1}^{n}f(x).
\]

如果 \(ab\mid x\)，那么一定存在唯一正整数 \(c\)，使得

\[
x=abc.
\]

因此，统计所有 \(x\le n\) 对应的 \((a,b)\)，等价于统计：

\[
abc\le n
\]

的所有 **有序正整数三元组** \((a,b,c)\)。

所以原问题变成：

\[
\boxed{S(n)=\#\{(a,b,c)\mid a,b,c\ge1,\ abc\le n\}}
\]

也就是三维除数函数的前缀和。

---

## 2. 为什么不能直接枚举

朴素做法：

```cpp
for (a = 1; a <= n; ++a)
    for (b = 1; a*b <= n; ++b)
        ans += n / (a*b);
```

复杂度过高。

注意 \(a,b,c\) 在乘法中完全对称，因此可以先规定

\[
a\le b\le c.
\]

只统计排序后的三元组，再根据三个数是否相同恢复其排列数量。

---

## 3. 排序后三种情况

对于

\[
a\le b\le c,
\]

有三种情况。

### 情况一：\(a<b<c\)

三个数字互不相同，可以任意排列：

\[
3!=6
\]

种。

### 情况二：恰好两个相等

例如

\[
a=a<c
\]

或者

\[
a<b=b.
\]

排列数量为

\[
\frac{3!}{2!}=3.
\]

### 情况三：\(a=b=c\)

只有

\[
1
\]

种排列。

---

## 4. 枚举 \(a,b\)，一次统计所有 \(c\)

固定 \(a,b\)，满足

\[
a\le b\le c.
\]

由

\[
abc\le n
\]

得到

\[
c\le \left\lfloor\frac{n}{ab}\right\rfloor.
\]

记

\[
C=\left\lfloor\frac{n}{ab}\right\rfloor.
\]

那么

\[
b\le c\le C.
\]

所以不需要枚举 \(c\)，直接统计整个区间即可。

为了确保至少存在一个 \(c\ge b\)，需要

\[
abb\le n.
\]

因此固定 \(a\) 后：

\[
a\le b\le \sqrt{\frac na}.
\]

而因为

\[
a\le b\le c,
\]

必然

\[
a^3\le abc\le n,
\]

所以

\[
a\le \sqrt[3]n.
\]

这就是 \(O(n^{2/3})\) 的来源。

---

# 5. 每个 \((a,b)\) 的贡献

这里是整道题最关键的地方。

### 当 \(a=b\)

此时

\[
a=b\le c\le C.
\]

其中：

- \(c=b\)：即 \(a=b=c\)，贡献 \(1\)；
- \(c>b\)：形如 \(a=a<c\)，每个有 \(3\) 种排列。

共有 \(C-b\) 个 \(c>b\)。

所以贡献：

\[
\boxed{1+3(C-b)}
\]

---

### 当 \(a<b\)

此时：

- \(c=b\)：形如 \(a<b=b\)，贡献 \(3\)；
- \(c>b\)：三个互不相同，每个贡献 \(6\)。

因此：

\[
\boxed{3+6(C-b)}
\]

---

## 6. 一个小优化

固定 \(a\)，令

\[
m=\left\lfloor\frac na\right\rfloor.
\]

则

\[
\left\lfloor\frac{n}{ab}\right\rfloor
=
\left\lfloor\frac{m}{b}\right\rfloor.
\]

所以代码里可以直接写：

```cpp
long long m = n / a;
long long c = m / b;
```

而 \(b\) 的范围就是

\[
b^2\le m.
\]

这样避免频繁计算 \(a\times b\)。

---

## 7. 正确性说明

我们只枚举

\[
a\le b\le c
\]

的三元组。

任意一个有序合法三元组 \((x,y,z)\)，排序之后一定唯一得到一个

\[
a\le b\le c.
\]

反过来：

- \(a<b<c\) 恢复出恰好 6 个有序三元组；
- \(a=b<c\) 或 \(a<b=c\) 恢复出恰好 3 个；
- \(a=b=c\) 恢复出恰好 1 个。

因此每个有序三元组被统计恰好一次，没有遗漏，也没有重复。

---

## 8. 复杂度

枚举：

\[
a\le n^{1/3},
\]

固定 \(a\) 后：

\[
b\le \sqrt{\frac na}.
\]

总枚举次数约为

\[
\sum_{a=1}^{n^{1/3}}\sqrt{\frac na}
=
O(n^{2/3}).
\]

所以：

\[
\boxed{\text{时间复杂度 }O(n^{2/3})}
\]

\[
\boxed{\text{空间复杂度 }O(1)}
\]

当 \(n=10^{11}\) 时，实际内层循环总次数大约只有三千万级，C++ 可以处理。

答案也可以安全使用 `long long`。粗略上界为

\[
nH_n^2<n(1+\ln n)^2<10^{14},
\]

远小于 `long long` 上限。

# 9. AC 代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

using int64 = long long;

// floor(sqrt(x))
static inline int64 isqrt(int64 x) {
    int64 r = (int64)sqrtl((long double)x);

    while ((r + 1) * (r + 1) <= x) ++r;
    while (r * r > x) --r;

    return r;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int64 n;
    int cas = 0;

    while (cin >> n) {
        int64 ans = 0;

        // a 是三个数中最小的那个
        // 必须有 a^3 <= n
        for (int64 a = 1; a * a * a <= n; ++a) {
            int64 m = n / a;

            // a <= b <= c
            // 存在 c >= b 的条件为：
            // a * b * b <= n
            // 即 b^2 <= floor(n / a)
            int64 limit = isqrt(m);

            for (int64 b = a; b <= limit; ++b) {
                // C = floor(n / (a*b))
                //   = floor(floor(n/a) / b)
                int64 C = m / b;

                if (a == b) {
                    // c = b: a = b = c，1 种
                    // c > b: a = b < c，每个 3 种排列
                    ans += 1 + 3 * (C - b);
                } else {
                    // c = b: a < b = c，3 种排列
                    // c > b: a < b < c，每个 6 种排列
                    ans += 3 + 6 * (C - b);
                }
            }
        }

        cout << "Case " << ++cas << ": " << ans << '\n';
    }

    return 0;
}
```

以 \(n=6\) 为例，该算法得到 \(25\)，与样例一致。样例中的全部结果：

```text
Case 1: 1
Case 2: 7
Case 3: 25
Case 4: 53
Case 5: 95
Case 6: 161
Case 7: 246
```

这题最值得记住的转换就是：

\[
\boxed{\sum_{x\le n}f(x)
\quad\Longleftrightarrow\quad
\#\{(a,b,c):abc\le n\}}
\]

然后利用乘法的对称性，只枚举 \(a\le b\le c\)，就能把三重枚举压缩到 \(O(n^{2/3})\)。
