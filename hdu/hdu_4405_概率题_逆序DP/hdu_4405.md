这道题是一道很典型的 **期望 DP + 逆序递推**。

关键点在于：所有移动（掷骰子或航线）都只会从编号较小的位置移动到编号更大的位置，因此不存在环，我们可以直接从终点 `N` 向前倒推期望。

## 1. 状态定义

定义：

\[
dp[i] = \text{从格子 }i\text{ 出发，到游戏结束还需要掷骰子的期望次数}
\]

当已经到达或超过 `N` 时游戏结束，所以：

\[
dp[N]=0
\]

实际计算中，掷骰子可能直接越过 `N`，这种情况对应后续期望也是 `0`。

---

## 2. 普通格子的转移

如果格子 `i` **没有航线**，那么必须掷一次骰子。

骰子六个面的概率相同，因此：

\[
dp[i]
=
1+
\frac{
dp[i+1]+dp[i+2]+\cdots+dp[i+6]
}{6}
\]

其中，如果

\[
i+k\ge N
\]

说明这一骰直接结束游戏，这部分期望为 `0`。

因此可以写成：

\[
dp[i]
=
1+\frac16\sum_{k=1}^{6}
\begin{cases}
dp[i+k],&i+k<N\\
0,&i+k\ge N
\end{cases}
\]

注意这里的 `1` 表示当前这一次掷骰子。

---

## 3. 有航线的格子

如果格子 `i` 有航线：

\[
i\rightarrow y
\]

根据题意，乘坐航线 **不需要掷骰子**。

所以：

\[
dp[i]=dp[y]
\]

而且题目说：

> If there is another flight line from Yi, Hzz can take the flight line continuously.

也就是说可能：

\[
i\rightarrow y\rightarrow z\rightarrow \cdots
\]

但我们完全不需要专门处理这个链。

因为所有航线都满足：

\[
X_i<Y_i
\]

我们按照

\[
N-1,N-2,\ldots,0
\]

逆序计算。

计算 `dp[i]` 时，`dp[y]` 一定已经算好了。如果 `y` 还有航线，那么 `dp[y]` 本身已经等价于最终航线终点的期望。

因此：

```cpp
dp[i] = dp[fly[i]];
```

即可。

---

## 4. 为什么一定要逆序 DP？

无论普通移动还是航线，都只会：

\[
i\rightarrow j,\quad j>i
\]

所以 `dp[i]` 只依赖编号比 `i` 大的状态。

因此从右向左计算：

```text
N-1, N-2, ..., 1, 0
```

所有依赖都已经提前计算完成。

---

## 5. 样例 1

```text
N = 2
M = 0
```

有：

\[
dp[2]=0
\]

位置 `1`：

掷出 `1~6` 都会结束：

\[
dp[1]=1
\]

位置 `0`：

只有掷出 `1` 会落到位置 `1`，掷出 `2~6` 都直接结束。

所以：

\[
dp[0]
=
1+\frac{dp[1]}6
\]

\[
=1+\frac16
=1.166666\ldots
\]

输出：

```text
1.1667
```

与样例一致。

---

## 6. 直接实现

每个状态最多检查 6 个位置，因此时间复杂度：

\[
O(6N+M)=O(N+M)
\]

空间复杂度：

\[
O(N)
\]

`N <= 100000`，完全没有问题。

---

## 7. 一个容易写错的细节

这里判断是：

```cpp
if (i + k < N)
```

而不是：

```cpp
if (i + k <= N)
```

当然，即使写成 `<= N`，只要设定了

```cpp
dp[N] = 0;
```

结果其实也不会错。

因为题目规定：

> `i+x` equal to **or greater than N**

就直接结束。

所以从语义上说：

\[
dp[j]=0,\quad j\ge N
\]

即可。

---

## 8. 还可以用滑动窗口优化

普通位置需要：

\[
dp[i+1]+\cdots+dp[i+6]
\]

由于只有 6 项，当前 `O(6N)` 已经非常快，**没必要优化**。

如果骰子不是 6 面，而是有例如 \(10^5\) 个可能结果，那么可以维护滑动窗口，把递推进一步降到严格的 `O(N)`。

这题最核心的识别就是：

> **航线不增加掷骰次数，所以有航线时直接 `dp[i]=dp[y]`；没有航线时才进行 `1 + 六个后继状态平均值`。**
