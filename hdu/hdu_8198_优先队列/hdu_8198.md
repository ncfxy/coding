设当前两个集合大小分别是 \(x,y\)。题目已经告诉我们，一次“玉米式合并”的代价是

\[
\max(x,y),
\]

合并后集合大小变成 \(x+y\)。

这道题的最优结构其实非常漂亮：

> **把所有集合按大小从大到小排序，然后先合并最大的两个，再不断把当前大集合与下一个集合合并。**

若排序后

\[
a_1\ge a_2\ge\cdots\ge a_n,
\]

最大总代价就是

\[
\boxed{\sum_{i=1}^{n}(n-i)a_i}.
\]

例如样例 `1 10 100` 排序成 `100 10 1`：

\[
2\times100+1\times10=210.
\]

下面证明为什么。

---

## 1. 把一次合并的代价分摊到元素上

考虑整个合并过程形成的一棵二叉树。

叶子就是最初的 \(n\) 个集合，每个叶子的权值为 \(a_i\)。

某次合并：

\[
X,Y\rightarrow X\cup Y
\]

假设

\[
|X|\ge |Y|,
\]

那么这一轮代价为

\[
|X|.
\]

我们可以把这 \(|X|\) 的代价理解成：

> 给属于 \(X\) 的每个元素各计算一次贡献。

也就是说，在这个合并结点上，我们标记较大的那个子树。

对于第 \(i\) 个原始集合，设它在从叶子到根的过程中，一共被包含在“较大子树”中 \(c_i\) 次。

那么总答案就是

\[
\sum_{i=1}^n a_i c_i.
\]

问题就转化为了：

> \(c_i\) 最多能够有多大？

---

## 2. \(c_i\) 有一个重要限制

把所有 \(c_i\) 从大到小排序：

\[
c_1'\ge c_2'\ge\cdots\ge c_n'.
\]

有：

\[
\boxed{c_i'\le n-i}.
\]

也就是

\[
c_1'\le n-1,\quad
c_2'\le n-2,\quad
\dots,\quad
c_n'\le0.
\]

### 为什么？

更一般地，我们证明：

\[
\#\{i:c_i\ge k\}\le n-k.
\]

也就是说，至少有 \(k\) 个叶子的贡献次数小于 \(k\)。

可以对合并树的叶子数量归纳。

假设根结点的两个子树分别有 \(p,q\) 个叶子，并且根结点标记了第一个子树。

那么：

- 第一个子树中的每个 \(c\) 都额外 \(+1\)；
- 第二个子树不增加。

因此贡献次数至少为 \(k\) 的叶子数量为

\[
N_k=N^{(1)}_{k-1}+N^{(2)}_k.
\]

根据归纳假设，

\[
N^{(1)}_{k-1}\le \max(0,p-k+1),
\]

\[
N^{(2)}_k\le \max(0,q-k).
\]

两者相加一定不超过

\[
p+q-k=n-k.
\]

所以

\[
N_k\le n-k.
\]

于是得到

\[
c_i'\le n-i.
\]

---

## 3. 如何让总代价最大？

我们已经知道，无论采用什么合并方案，其贡献次数排序后都满足

\[
c_i'\le n-i.
\]

另一方面，所有 \(a_i>0\)。

为了最大化

\[
\sum a_i c_i,
\]

根据重排不等式，显然应该让：

- 最大的 \(a_i\) 对应最大的 \(c_i\)；
- 第二大的 \(a_i\) 对应第二大的 \(c_i\)；
- ……

于是答案最多为

\[
(n-1)a_1+(n-2)a_2+\cdots+a_{n-1},
\]

其中

\[
a_1\ge a_2\ge\cdots\ge a_n.
\]

即

\[
\boxed{\operatorname{Ans}
=\sum_{i=1}^{n}(n-i)a_i}.
\]

剩下只需要证明这个上界真的能达到。

---

## 4. 构造达到上界的方案

还是假设

\[
a_1\ge a_2\ge\cdots\ge a_n.
\]

先合并 \(a_1,a_2\)。

代价：

\[
a_1.
\]

新集合大小：

\[
a_1+a_2.
\]

然后与 \(a_3\) 合并。

因为

\[
a_1+a_2\ge a_3,
\]

所以代价为

\[
a_1+a_2.
\]

继续与 \(a_4\) 合并，代价为

\[
a_1+a_2+a_3.
\]

……

总代价：

\[
a_1
+(a_1+a_2)
+(a_1+a_2+a_3)
+\cdots
+(a_1+\cdots+a_{n-1}).
\]

整理得到

\[
(n-1)a_1+(n-2)a_2+\cdots+a_{n-1}.
\]

恰好达到之前的上界。

所以这就是答案。

---

## 5. 算法

对于每组数据：

1. 将 \(a\) 从大到小排序；
2. 计算

\[
\sum_{i=0}^{n-1}(n-1-i)a_i.
\]

复杂度：

\[
O(n\log n).
\]

所有测试的 \(n\) 之和不超过 \(5\times10^5\)，完全足够。

### 注意整数溢出

最大答案大约为

\[
2\times10^9\cdot
\frac{10^5(10^5-1)}2
\approx 10^{19},
\]

已经可能超过有符号 `long long` 的

\[
9.22\times10^{18}.
\]

所以建议使用 `__int128`。

---

## C++17 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using i128 = __int128_t;

void print_i128(i128 x) {
    if (x == 0) {
        cout << 0;
        return;
    }

    string s;
    while (x > 0) {
        s.push_back(char('0' + x % 10));
        x /= 10;
    }
    reverse(s.begin(), s.end());
    cout << s;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        int n;
        cin >> n;

        vector<long long> a(n);
        for (auto &x : a) cin >> x;

        sort(a.begin(), a.end(), greater<long long>());

        i128 ans = 0;

        for (int i = 0; i < n; ++i) {
            ans += (i128)a[i] * (n - 1 - i);
        }

        print_i128(ans);
        cout << '\n';
    }

    return 0;
}
```

### 样例

排序后：

\[
100,10,1
\]

于是

\[
\text{Ans}
=100\times2+10\times1+1\times0
=210.
\]

对应实际操作就是

\[
10+100\quad\text{代价 }100,
\]

得到大小 \(110\)，再：

\[
110+1\quad\text{代价 }110.
\]

总计

\[
100+110=210.
\]

因此核心结论可以记成一句话：

\[
\boxed{\text{降序排序后，第 }i\text{ 大的集合最多贡献 }n-i\text{ 次。}}
\]
