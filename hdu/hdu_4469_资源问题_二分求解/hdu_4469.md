这道题的难点在于：**训练村民需要提前支付食物，而且训练完成前新村民不能工作**。直接按秒模拟显然不行，答案可能达到 \(10^{18}\) 级别。

核心可以转化成“村民工作秒数”，再利用一个重要性质：**由于 \(X\le 10^5\)，因为食物不足而造成的训练间隔最多只需要显式处理 \(10^5\) 个村民；之后训练一定变成每隔 \(T\) 秒连续进行。**

---

## 1. 把资源转成“工作秒数”

一个村民工作 1 秒只能采集一种资源。

因此如果不考虑训练，获得目标资源至少需要：

\[
F=\left\lceil\frac{A_2}{A_1}\right\rceil
\]

个“食物工作秒”，以及

\[
Q=
\left\lceil\frac{B_2}{B_1}\right\rceil+
\left\lceil\frac{C_2}{C_1}\right\rceil+
\left\lceil\frac{D_2}{D_1}\right\rceil
\]

个其他资源工作秒。

如果总共训练了 \(k\) 个新村民，需要额外花掉 \(kX\) 食物。

因此食物一共至少需要采集：

\[
A_2+kX
\]

对应的工作秒数为

\[
F(k)=
\left\lceil
\frac{A_2+kX}{A_1}
\right\rceil
\]

所以固定训练 \(k\) 个村民以后，总工作量需求就是

\[
Q+F(k)
\]

但还有一个额外限制：

> 第 \(j\) 个村民开始训练时，必须已经采到了至少 \(jX\) 食物。

因此还要研究训练时间。

---

# 2. 固定训练数量时，一定越早训练越好

设第 \(j\) 个新村民在第

\[
s_j
\]

秒的**开始时刻**开始训练。

训练耗时 \(T\) 秒，所以它从第

\[
s_j+T
\]

秒开始工作。

例如 \(T=1,s_j=2\)，那么：

- 第 2 秒训练；
- 第 3 秒开始工作。

符合样例。

对于固定的训练数量 \(k\)，把每个村民尽可能早训练一定不会更差：

- 训练费用不变；
- 越早训练，新村民能贡献的工作秒数越多；
- 木、石、金都没有中间截止时间。

所以只需要计算：

> 第 \(j\) 个村民最早什么时候能开始训练？

---

# 3. 推导 \(s_j\)

考虑第 \(j\) 个村民在第 \(s_j\) 秒开始训练。

在此之前，总共必须采集至少

\[
jX
\]

食物。

对应至少：

\[
P_j=
\left\lceil\frac{jX}{A_1}\right\rceil
\]

个食物工作秒。

---

在第 \(s_j\) 秒开始之前，最初的 \(N\) 个村民已经工作了：

\[
N(s_j-1)
\]

个工作秒。

前面第 \(i\) 个训练出来的村民，从

\[
s_i+T
\]

开始工作。

到 \(s_j\) 开始之前，它贡献：

\[
s_j-s_i-T
\]

个工作秒。

因此总工作秒为

\[
N(s_j-1)+
\sum_{i=1}^{j-1}(s_j-s_i-T)
\]

整理：

\[
(N+j-1)s_j
-
N
-
\sum_{i=1}^{j-1}s_i
-
(j-1)T
\]

为了能够支付第 \(j\) 次训练，需要：

\[
(N+j-1)s_j
-
N
-
\sum_{i<j}s_i
-
(j-1)T
\ge P_j
\]

所以由食物决定的最早时间：

\[
s_j\ge
\left\lceil
\frac{
P_j+N+\sum_{i<j}s_i+(j-1)T
}{
N+j-1
}
\right\rceil
\]

另外城镇中心只有一个，第 \(j-1\) 个训练完成后才能训练第 \(j\) 个：

\[
s_j\ge s_{j-1}+T
\]

于是：

\[
\boxed{
s_j=
\max\left(
s_{j-1}+T,\;
\left\lceil
\frac{
P_j+N+\sum_{i<j}s_i+(j-1)T
}{
N+j-1
}
\right\rceil
\right)
}
\]

维护前缀和

\[
S_j=\sum_{i=1}^j s_i
\]

就能 \(O(1)\) 算下一项。

---

# 4. 为什么最多只需要模拟 \(10^5\) 次？

这是整题最关键的优化。

假设第 \(j\) 个村民刚开始训练。

接下来 \(T\) 秒内，第 \(j\) 个新村民还不能工作，因此有：

\[
N+j-1
\]

个村民能够采集。

如果他们在这 \(T\) 秒中就能够采出下一次训练需要的 \(X\) 食物：

\[
(N+j-1)TA_1\ge X
\]

那么第 \(j+1\) 个村民一定可以在

\[
s_j+T
\]

立即开始训练。

并且以后村民只会越来越多，因此再也不会因为缺食物而中断训练。

令：

\[
R=
\left\lceil
\frac{X}{A_1T}
\right\rceil
\]

需要：

\[
N+j-1\ge R
\]

即

\[
j\ge R-N+1
\]

定义

\[
\boxed{
j_0=
\max\left(
1,\;
\left\lceil\frac{X}{A_1T}\right\rceil-N+1
\right)
}
\]

因为

\[
X\le10^5
\]

且 \(A_1,T\ge1\)，所以

\[
j_0\le10^5
\]

因此只需要显式计算前 \(j_0\) 次训练。

从 \(j_0\) 开始：

\[
s_{j_0+m}=s_{j_0}+mT
\]

变成等差数列。

---

# 5. 固定训练 \(k\) 个村民，需要多少时间？

假设全部 \(k\) 个村民都已经在答案时间 \(H\) 内训练完成。

初始 \(N\) 个村民贡献：

\[
NH
\]

第 \(i\) 个新村民从 \(s_i+T\) 秒工作到第 \(H\) 秒，共：

\[
H-s_i-T+1
\]

个工作秒。

所以总工作秒：

\[
NH+
\sum_{i=1}^k(H-s_i-T+1)
\]

即

\[
\boxed{
C(H,k)
=
(N+k)H-S_k-k(T-1)
}
\]

要满足资源需求：

\[
C(H,k)\ge Q+F(k)
\]

所以：

\[
H\ge
\left\lceil
\frac{
Q+F(k)+S_k+k(T-1)
}{
N+k
}
\right\rceil
\]

同时第 \(k\) 个村民必须已经完成训练：

\[
H\ge s_k+T
\]

因此固定 \(k\) 的最小时间是：

\[
\boxed{
H(k)=
\max\left(
s_k+T,\;
\left\lceil
\frac{
Q+F(k)+S_k+k(T-1)
}{
N+k
}
\right\rceil
\right)
}
\]

对于

\[
k<j_0
\]

直接枚举即可，总共最多 \(10^5\) 次。

\(k=0\) 时答案为：

\[
H(0)=
\left\lceil
\frac{
Q+\lceil A_2/A_1\rceil
}{N}
\right\rceil
\]

它还可以作为整个问题的答案上界。

---

# 6. 怎么处理 \(k\ge j_0\)？

从 \(j_0\) 开始：

设

\[
s_0=s_{j_0},\qquad
S_0=S_{j_0}
\]

令

\[
m=k-j_0
\]

则：

\[
s_k=s_0+mT
\]

以及

\[
S_k
=
S_0
+
ms_0
+
T\frac{m(m+1)}2
\]

可以 \(O(1)\) 求任意巨大 \(k\) 对应的数据。

但 \(k\) 可能达到 \(10^{18}\)，依然不能枚举。

我们二分最终时间 \(H\)。

---

## 7. 判定某个 \(H\) 是否可行

首先能在 \(H\) 内完成的最大训练数量满足：

\[
s_k+T\le H
\]

因此：

\[
k\le
j_0+
\left\lfloor
\frac{H-s_0-T}{T}
\right\rfloor
\]

记为 \(K\)。

对于任意 \(k\in[j_0,K]\)，定义剩余工作量：

\[
G(k)
=
C(H,k)-Q-F(k)
\]

如果存在：

\[
G(k)\ge0
\]

则 \(H\) 可行。

---

## 8. \(G(k)\) 是离散凹函数

增加第 \(k+1\) 个村民后，总工作量增加：

\[
H-s_{k+1}-T+1
\]

但食物工作量增加：

\[
F(k+1)-F(k)
\]

所以：

\[
G(k+1)-G(k)
=
H-s_{k+1}-T+1
-
(F(k+1)-F(k))
\]

因为连续训练阶段：

\[
s_{k+1}
\]

每增加一个 \(k\)，就增加恰好 \(T\)。

而

\[
F(k)=
\left\lceil
\frac{A_2+kX}{A_1}
\right\rceil
\]

其相邻增量只能是

\[
\left\lfloor\frac X{A_1}\right\rfloor
\]

或者

\[
\left\lceil\frac X{A_1}\right\rceil
\]

因此相邻的食物增量最多变化 1。

所以

\[
G(k+1)-G(k)
\]

是单调不增的。

换句话说：

\[
G(k)
\]

是一个**离散凹函数**。

因此可以二分寻找：

> 最后一个满足 \(G(k+1)-G(k)\ge0\) 的位置。

最大值就在附近。

于是一次时间判定只需要：

\[
O(\log 10^{18})
\]

---

# 9. 总复杂度

前面显式计算：

\[
O(j_0)\le O(10^5)
\]

之后二分答案，每次再二分离散凹函数最大值：

\[
O(\log^2 10^{18})
\]

所以单组总复杂度：

\[
\boxed{
O(10^5+\log^2 10^{18})
}
\]

空间：

\[
\boxed{O(10^5)}
\]

---

# 10. 注意整数范围

虽然答案本身最多大约 \(4\times10^{18}\)，但计算

\[
S_k\sim k^2T
\]

时可能达到 \(10^{37}\) 左右。

因此普通 `long long` 不够。

C++ 中需要用：

```cpp
__int128
```

其范围约为 \(10^{38}\)，刚好足够。
