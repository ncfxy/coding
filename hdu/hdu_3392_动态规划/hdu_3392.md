这道题的关键不是普通的二分图匹配，而是利用**身高排序后最优匹配一定不交叉**，再结合题目给出的

\[
|n-m|\le 100
\]

把原本 \(O(nm)\) 的 DP 优化到 \(O(\min(n,m)\cdot |n-m|)\)。

---

## 1. 问题转化

要求：

1. 匹配人数尽可能多；
2. 在此前提下，总身高差最小。

显然最大匹配数就是：

\[
\min(n,m)
\]

假设人数少的一方有 \(n\) 人，多的一方有 \(m\) 人，并令

\[
n\le m
\]

那么问题就变成：

> 给定 \(n\) 个人和 \(m\) 个人，必须把较少一方的 \(n\) 个人全部匹配，从较多一方的 \(m\) 个人中选出 \(n\) 人，使总身高差最小。

如果原本 \(n>m\)，直接交换男女数组即可。

---

## 2. 为什么可以先排序？

分别把两边身高排序：

\[
a_1\le a_2\le\cdots\le a_n
\]

\[
b_1\le b_2\le\cdots\le b_m
\]

最优解中一定可以保证匹配关系**不交叉**。

例如：

\[
a_i\le a_j,\qquad b_x\le b_y
\]

如果当前进行了交叉匹配：

- \(a_i\leftrightarrow b_y\)
- \(a_j\leftrightarrow b_x\)

那么有经典不等式：

\[
|a_i-b_x|+|a_j-b_y|
\le
|a_i-b_y|+|a_j-b_x|
\]

所以把交叉匹配改成顺序匹配不会更差。

因此排序以后，问题等价于：

> 从较长数组 \(b\) 中删掉 \(m-n\) 个元素，剩下的元素依次与 \(a\) 匹配。

---

## 3. 常规 DP

可以定义：

\[
f[i][j]
\]

表示：

> 已经匹配前 \(i\) 个较少一方的人，并且从较多一方中额外跳过了 \(j\) 个人时的最小代价。

那么当前第 \(i\) 个人对应考虑的是：

\[
b_{i+j}
\]

因为前面总共看过：

- \(i\) 个被匹配的人；
- \(j\) 个被跳过的人。

### 转移 1：匹配当前人

把 \(a_i\) 和 \(b_{i+j}\) 匹配：

\[
f[i][j]
=
f[i-1][j]+|a_i-b_{i+j}|
\]

### 转移 2：跳过当前较多一方的人

我们也可以不使用 \(b_{i+j}\)。

此时：

\[
f[i][j]=f[i][j-1]
\]

因此：

\[
\boxed{
f[i][j]
=
\min\left(
f[i-1][j]+|a_i-b_{i+j}|,
f[i][j-1]
\right)
}
\]

---

## 4. 为什么这个 DP 很快？

设：

\[
d=m-n
\]

题目明确保证：

\[
d\le 100
\]

我们根本不需要让第二维跑到 \(m\)，因为最多只会跳过 \(d\) 个人。

因此：

\[
0\le j\le d
\]

状态数量只有：

\[
n(d+1)
\]

最大约为：

\[
10000\times101
\]

也就是约 \(10^6\)，非常轻松。

---

## 5. 边界条件

当还没有匹配任何人时：

\[
f[0][j]=0
\]

这是因为如果最终允许跳过 \(j\) 个人，那么一开始跳过前面任意一些人都不产生匹配代价。

最终要求把较长数组中的 \(d=m-n\) 个多余人员全部处理掉，因此答案为：

\[
\boxed{f[n][d]}
\]

实际上这个 DP 可以滚动数组优化到 \(O(d)\) 空间。

---

## 6. 滚动数组

令 `pre[j]` 表示上一层 \(f[i-1][j]\)，`cur[j]` 表示当前层。

对于 \(j=0\)，不能跳过额外的人：

```cpp
cur[0] = pre[0] + abs(a[i - 1] - b[i - 1]);
```

对于 \(j\ge1\)：

```cpp
cur[j] = min(
    pre[j] + abs(a[i - 1] - b[i + j - 1]),
    cur[j - 1]
);
```

这里注意数组是 0 下标：

\[
a_i\rightarrow a[i-1]
\]

\[
b_{i+j}\rightarrow b[i+j-1]
\]

---

## 7. 样例分析

输入：

```text
2 3
1.5 2.0
1.5 1.7 2.0
```

人数较少的是男生：

\[
a=[1.5,2.0]
\]

女生：

\[
b=[1.5,1.7,2.0]
\]

需要从女生中跳过：

\[
3-2=1
\]

最优选择是跳过 `1.7`：

- \(1.5\leftrightarrow1.5\)
- \(2.0\leftrightarrow2.0\)

所以：

\[
|1.5-1.5|+|2.0-2.0|=0
\]

输出：

```text
0.000000
```

---

## 8. 复杂度

排序：

\[
O(n\log n+m\log m)
\]

DP：

\[
O(\min(n,m)\cdot|n-m|)
\]

由于：

\[
|n-m|\le100
\]

所以最坏只有大约 \(10^6\) 次 DP 转移。

空间复杂度：

\[
O(|n-m|)
\]

也就是最多约 101 个 `double`。

### 核心结论

这题真正的突破点就是题目特意给出的：

> `|n - m| <= 100`

它暗示我们不要写 \(O(nm)\) DP，而是把状态改成“**已经跳过多少个较多一方的人**”。

最终转移就是：

\[
\boxed{
f[i][j]=
\min\left(
f[i-1][j]+|a_i-b_{i+j}|,
f[i][j-1]
\right)
}
\]

这是一个典型的**排序 + 小差值 DP / 带状 DP**问题。
