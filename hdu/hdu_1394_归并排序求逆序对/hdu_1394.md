下面给出一份完整的解题报告，采用 **归并排序求初始逆序对 + \(O(1)\) 维护循环移位后的逆序对数量**，总复杂度为 \(O(n\log n)\)。

# Minimum Inversion Number

## 一、题意分析

给定一个长度为 \(n\) 的排列：

\[
a_1,a_2,\dots,a_n
\]

其中包含 `0 ~ n-1` 每个整数恰好一次。

对于一个序列，逆序对定义为满足：

\[
i<j,\quad a_i>a_j
\]

的二元组 \((i,j)\)。

现在可以把序列最前面的若干个元素移动到末尾，因此一共会产生 \(n\) 种循环移位后的序列：

\[
\begin{aligned}
&a_1,a_2,\dots,a_n\\
&a_2,a_3,\dots,a_n,a_1\\
&a_3,a_4,\dots,a_n,a_1,a_2\\
&\dots\\
&a_n,a_1,a_2,\dots,a_{n-1}
\end{aligned}
\]

要求这些序列中 **最小的逆序对数量**。

---

## 二、直接做法

最直接的方法是：

1. 枚举 \(n\) 个循环移位后的序列；
2. 对每个序列重新统计逆序对。

如果使用 \(O(n^2)\) 暴力统计逆序对，总复杂度达到：

\[
O(n^3)
\]

显然没有必要。

即使每次都使用归并排序统计逆序对，也需要：

\[
O(n^2\log n)
\]

实际上，相邻两个循环排列之间只移动了一个元素，因此可以直接维护逆序对数量。

---

# 三、关键观察：循环移位时逆序对如何变化

假设当前序列为：

\[
x,b_1,b_2,\dots,b_{n-1}
\]

把第一个元素 \(x\) 移动到末尾后变成：

\[
b_1,b_2,\dots,b_{n-1},x
\]

我们比较移动前后的逆序对。

注意：

> 除了 \(x\) 以外，其余 \(n-1\) 个元素之间的相对顺序完全没有发生变化。

因此，逆序对数量的变化只和 \(x\) 有关。

---

## 四、移动前 \(x\) 贡献多少逆序对

移动前 \(x\) 位于整个序列最前面。

对于后面的元素 \(y\)，只要满足：

\[
x>y
\]

就会产生逆序对 \((x,y)\)。

由于整个序列恰好是：

\[
0,1,2,\dots,n-1
\]

的一个排列。

比 \(x\) 小的数字恰好为：

\[
0,1,\dots,x-1
\]

共有：

\[
x
\]

个。

因此移动前，\(x\) 参与的逆序对数量为：

\[
\boxed{x}
\]

---

# 五、移动后 \(x\) 贡献多少逆序对

把 \(x\) 移动到最后以后：

\[
b_1,b_2,\dots,b_{n-1},x
\]

此时 \(x\) 位于最后。

因此只有前面的元素 \(y\) 满足：

\[
y>x
\]

时，\((y,x)\) 才是逆序对。

比 \(x\) 大的数字为：

\[
x+1,x+2,\dots,n-1
\]

数量为：

\[
n-1-x
\]

因此移动后，\(x\) 参与的逆序对数量为：

\[
\boxed{n-1-x}
\]

---

# 六、得到逆序对递推公式

设移动之前的逆序对数量为：

\[
inv
\]

移动 \(x\) 时：

- 删除原来的 \(x\) 个逆序对；
- 增加新的 \(n-1-x\) 个逆序对。

所以：

\[
inv'
=
inv-x+(n-1-x)
\]

整理得：

\[
\boxed{
inv'=inv+n-1-2x
}
\]

这就是本题最关键的公式。

因此，每进行一次循环移位，我们都可以在：

\[
\boxed{O(1)}
\]

时间得到新的逆序对数量。

---

# 七、问题转化

现在问题只剩下：

> 如何快速求出原始排列的逆序对数量？

可以使用经典的 **归并排序统计逆序对**。

---

# 八、归并排序统计逆序对

假设当前递归处理区间：

\[
[l,r]
\]

首先划分成：

\[
[l,mid]
\]

和：

\[
[mid+1,r]
\]

分别递归排序。

归并时，两边都已经有序。

假设当前：

```text
左边：a[i]
右边：a[j]
```

如果：

\[
a_i\le a_j
\]

那么不会产生新的跨区间逆序对，直接取 `a[i]`。

但如果：

\[
a_i>a_j
\]

由于左半部分已经有序，因此：

\[
a_i,a_{i+1},\dots,a_{mid}
\]

全部满足：

\[
>a_j
\]

于是一次可以统计：

\[
mid-i+1
\]

个逆序对。

即：

```cpp
cnt += mid - i + 1;
```

整个归并排序的时间复杂度为：

\[
O(n\log n)
\]

---

# 九、完整算法

对于每一组测试数据：

### 第一步

读入原排列：

\[
a_0,a_1,\dots,a_{n-1}
\]

### 第二步

复制数组：

```cpp
b = a
```

因为归并排序会改变数组顺序，而之后还需要按照原数组顺序依次进行循环移位。

### 第三步

使用归并排序统计原排列的逆序对数量：

\[
inv
\]

初始化：

\[
ans=inv
\]

### 第四步

依次枚举：

```text
a[0], a[1], ..., a[n-2]
```

表示把当前最前面的元素移动到最后。

对于：

\[
x=a_i
\]

使用：

\[
inv=inv+n-1-2x
\]

更新逆序对数量。

然后：

\[
ans=\min(ans,inv)
\]

最终输出 `ans`。

---

# 十、为什么按照原数组顺序枚举即可

这一点很容易产生疑问。

原数组：

```text
a0 a1 a2 a3 ... an-1
```

第一次移动：

```text
a1 a2 a3 ... an-1 a0
```

被移动的是：

```text
a0
```

第二次移动：

```text
a2 a3 ... an-1 a0 a1
```

被移动的是：

```text
a1
```

第三次被移动的是：

```text
a2
```

……

所以每一次被移到末尾的元素依次正好是：

```cpp
a[0], a[1], a[2], ...
```

因此完全不需要真的执行数组旋转。

直接遍历原数组即可。

# 十一、正确性证明

下面证明算法一定能够得到答案。

## 引理 1

将当前序列第一个元素 \(x\) 移到最后时，除了包含 \(x\) 的逆序对之外，其他逆序对状态不会发生变化。

### 证明

设除了 \(x\) 以外任意两个元素为 \(a_i,a_j\)。

移动 \(x\) 前后，这两个元素之间：

- 数值没有变化；
- 相对先后顺序没有变化。

因此：

\[
a_i>a_j
\]

是否构成逆序对不会改变。

所以逆序对数量的变化只来自于包含 \(x\) 的逆序对。

引理成立。

---

## 引理 2

移动前 \(x\) 参与的逆序对数量为 \(x\)。

### 证明

移动前 \(x\) 位于最前面。

它与后面元素构成逆序对，当且仅当：

\[
x>y
\]

由于数组是 `0 ~ n-1` 的排列，比 \(x\) 小的数字恰好有：

\[
x
\]

个。

因此 \(x\) 参与 \(x\) 个逆序对。

引理成立。

---

## 引理 3

移动后 \(x\) 参与的逆序对数量为：

\[
n-1-x
\]

### 证明

移动后 \(x\) 位于最后。

它与前面的元素构成逆序对，当且仅当：

\[
y>x
\]

在 `0 ~ n-1` 中，比 \(x\) 大的数字恰好有：

\[
n-1-x
\]

个。

所以移动后 \(x\) 参与的逆序对数量为：

\[
n-1-x
\]

引理成立。

---

## 定理

如果当前逆序对数量为 \(inv\)，移动第一个元素 \(x\) 到最后后：

\[
inv'=inv+n-1-2x
\]

### 证明

根据引理 1，只有涉及 \(x\) 的逆序对发生变化。

根据引理 2，需要删除原来的：

\[
x
\]

个逆序对。

根据引理 3，需要增加：

\[
n-1-x
\]

个逆序对。

因此：

\[
\begin{aligned}
inv'
&=inv-x+(n-1-x)\\
&=inv+n-1-2x
\end{aligned}
\]

所以递推公式正确。

由于我们从原排列开始，依次应用该公式，就能够正确得到全部 \(n\) 个循环移位排列的逆序对数量。

取其中最小值即为最终答案。

证毕。

# 十二、复杂度分析

## 初始逆序对

使用归并排序：

\[
O(n\log n)
\]

## 枚举循环移位

一共有 \(n-1\) 次，每次 \(O(1)\)：

\[
O(n)
\]

因此总时间复杂度：

\[
\boxed{O(n\log n)}
\]

使用两个长度为 \(n\) 的数组：

\[
\boxed{O(n)}
\]

空间复杂度。

# 十三、参考代码

# 十四、核心代码浓缩

如果已经理解归并排序，那么本题真正需要记住的只有下面这一段：

```cpp
ll inv = mergeSort(b, tmp, 0, n - 1);
ll ans = inv;

for (int i = 0; i < n - 1; ++i) {
    inv += n - 1 - 2LL * a[i];
    ans = min(ans, inv);
}
```

本题的核心结论就是：

\[
\boxed{
\text{把 }x\text{ 从序列开头移到末尾}
\quad\Longrightarrow\quad
inv\mathrel{+}=n-1-2x
}
\]

再配合归并排序 \(O(n\log n)\) 求初始逆序对，即可在：

\[
\boxed{O(n\log n)}
\]

时间内解决整个问题。
