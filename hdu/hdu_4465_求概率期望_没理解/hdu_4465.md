这道题可以看成一个**负二项分布 + 期望**问题。真正的难点有两个：

1. 推出“第一次打开空盒子时，另一个盒子还剩 \(k\) 颗糖”的概率。
2. \(n\le 2\times 10^5\)，直接计算组合数和 \(p^{n+1}\) 会严重溢出/下溢，需要稳定地计算概率。

---

## 1. 停止时发生了什么？

设两个盒子为 \(A,B\)。

每天：

- 以概率 \(p\) 选择 \(A\)
- 以概率 \(q=1-p\) 选择 \(B\)

每个盒子最开始有 \(n\) 颗糖。

注意：

> LazyChild 第一次伤心，是某个盒子已经被成功取过 \(n\) 次之后，又被选择了第 \(n+1\) 次。

例如最终是打开 \(A\) 时发现空了。

设此时 \(B\) 在之前一共被选择了 \(j\) 次。

因为还没有更早结束，所以一定有

\[
0\le j\le n.
\]

此时 \(B\) 还剩

\[
n-j
\]

颗糖。

---

# 2. \(A\) 先空时的概率

假设最后打开空盒子的是 \(A\)。

在最后一次失败之前：

- \(A\) 已经被选择了恰好 \(n\) 次；
- \(B\) 被选择了 \(j\) 次。

因此前面一共有

\[
n+j
\]

次选择。

其中选择 \(A\) 的 \(n\) 次可以任意分布，所以方案数为

\[
\binom{n+j}{j}.
\]

这些选择的概率为

\[
p^nq^j.
\]

接下来还必须再次选择 \(A\)，概率为 \(p\)。

所以：

\[
P(A\text{ 先空，并且 }B\text{ 已吃 }j\text{ 颗})
=
\binom{n+j}{j}p^{n+1}q^j.
\]

对应剩余糖果数量为

\[
n-j.
\]

于是这一部分对期望的贡献为

\[
\sum_{j=0}^{n}
(n-j)
\binom{n+j}{j}
p^{n+1}q^j.
\]

---

## 3. \(B\) 先空

完全对称。

概率为

\[
\binom{n+j}{j}q^{n+1}p^j,
\]

因此贡献为

\[
\sum_{j=0}^{n}
(n-j)
\binom{n+j}{j}
q^{n+1}p^j.
\]

所以最终答案：

\[
\boxed{
E=
\sum_{j=0}^{n}
(n-j)\binom{n+j}{j}
\left(
p^{n+1}q^j
+
q^{n+1}p^j
\right)
}
\]

其中 \(q=1-p\)。

---

# 4. 不能直接算组合数

如果直接计算

\[
\binom{n+j}{j}
\]

当 \(n=2\times10^5\) 时会巨大无比。

可以考虑递推。

定义

\[
T_j=
\binom{n+j}{j}a^{n+1}b^j.
\]

其中：

- 对 \(A\) 先空：\(a=p,b=q\)
- 对 \(B\) 先空：\(a=q,b=p\)

有

\[
\frac{T_{j+1}}{T_j}
=
\frac{\binom{n+j+1}{j+1}}
     {\binom{n+j}{j}}
b
\]

而

\[
\frac{\binom{n+j+1}{j+1}}
     {\binom{n+j}{j}}
=
\frac{n+j+1}{j+1}.
\]

所以

\[
\boxed{
T_{j+1}
=
T_j\cdot
\frac{n+j+1}{j+1}\cdot b
}
\]

看起来可以从

\[
T_0=a^{n+1}
\]

开始。

但是这里有一个很大的坑。

---

# 5. 数值下溢问题

例如：

\[
n=200000,\quad p=0.5.
\]

那么

\[
T_0=0.5^{200001},
\]

double 早就下溢成 \(0\) 了。

但真正靠近 \(j=n\) 的概率并不小。

所以**不能从 \(j=0\) 开始递推**。

---

# 6. 从概率最大的地方开始

考虑

\[
T_j=
\binom{n+j}{j}a^{n+1}b^j.
\]

比较相邻两项：

\[
\frac{T_j}{T_{j-1}}
=
\frac{n+j}{j}b.
\]

当它大于等于 1 时，数列仍然递增：

\[
\frac{n+j}{j}b\ge1.
\]

因为

\[
a+b=1,
\]

所以

\[
(n+j)b\ge j
\]

即

\[
nb\ge ja.
\]

因此概率最大的位置大约是

\[
\boxed{
m=\left\lfloor\frac{nb}{a}\right\rfloor
}
\]

同时我们只需要 \(0\le j\le n\)，所以

\[
m=\min\left(n,\left\lfloor\frac{nb}{a}\right\rfloor\right).
\]

---

# 7. 先计算 \(T_m\)

用对数计算：

\[
\ln T_m
=
\ln\binom{n+m}{m}
+
(n+1)\ln a
+
m\ln b.
\]

其中

\[
\ln\binom{n+m}{m}
=
\ln\Gamma(n+m+1)
-\ln\Gamma(n+1)
-\ln\Gamma(m+1).
\]

C++ 中可以使用 `lgammal`。

因此：

```cpp
long double logT =
    lgammal(n + m + 1.0L)
    - lgammal(n + 1.0L)
    - lgammal(m + 1.0L)
    + (n + 1.0L) * logl(a)
    + m * logl(b);

long double t = expl(logT);
```

因为 \(m\) 在概率峰值附近，所以这个值通常不会出现严重下溢。

---

# 8. 向右递推

已经知道 \(T_m\)。

对于 \(j\ge m\)：

\[
\boxed{
T_{j+1}
=
T_j
\frac{n+j+1}{j+1}b
}
\]

由于已经经过概率峰值，所以基本是越来越小的，数值稳定。

---

# 9. 向左递推

由

\[
T_j
=
T_{j-1}
\frac{n+j}{j}b
\]

反推：

\[
\boxed{
T_{j-1}
=
T_j
\frac{j}{(n+j)b}
}
\]

同样，因为从峰值向左走，也是越来越小。

因此整个计算过程非常稳定。

---

# 10. 定义一个函数

计算

\[
F(a,b)=
\sum_{j=0}^{n}
(n-j)
\binom{n+j}{j}a^{n+1}b^j.
\]

那么：

\[
\boxed{
Answer=F(p,q)+F(q,p)
}
\]

---

# 11. 边界情况

当

\[
p=1
\]

时，只会选择第一个盒子。

连续吃掉第一个盒子的 \(n\) 颗糖以后，下一天再次打开第一个盒子，发现空了。

此时第二个盒子一颗都没吃，所以还有

\[
n
\]

颗。

\(p=0\) 同理。

答案都是

\[
n.
\]

代码中的通用函数也要特别处理 \(a=0\) 或 \(b=0\)，避免 `log(0)`。

---

# 12. 复杂度

每个方向遍历最多 \(n\) 项，两种盒子各算一次：

\[
O(n)
\]

空间复杂度：

\[
O(1)
\]

对于

\[
n\le2\times10^5
\]

完全足够。

---

## 13. 用样例理解一下

例如：

```text
10 0.400000
```

考虑“第一个盒子先被打开为空”。

如果第二个盒子此前吃了 \(j\) 颗，那么：

\[
P_j=
\binom{10+j}{j}
0.4^{11}
0.6^j.
\]

剩余：

\[
10-j.
\]

再加上第二个盒子先空的对称情况：

\[
\binom{10+j}{j}
0.6^{11}
0.4^j.
\]

于是

\[
E=
\sum_{j=0}^{10}
(10-j)\binom{10+j}{j}
\left(
0.4^{11}0.6^j
+
0.6^{11}0.4^j
\right),
\]

计算得到

\[
3.5281754529\ldots
\]

输出：

```text
Case 1: 3.528175
```

与样例一致。

这道题最值得注意的地方就是：**概率公式本身并不难，真正会导致 WA 的往往是从 \(p^{n+1}\) 开始递推造成的浮点下溢。** 从负二项分布的峰值位置向两边递推，可以很好地解决这个问题。
