这道题的核心就是：**计算每个 DNA 字符串的逆序对数量，然后按照逆序对数量从小到大稳定排序**。

由于字符只有 `A、C、G、T` 四种，甚至不需要归并排序，可以在线性时间内统计每个字符串的逆序对。

## 一、题意分析

对于字符串 `s`，如果存在两个位置：

\[
i<j,\quad s_i>s_j
\]

那么 `(i,j)` 就构成一个逆序对。

例如：

```text
DAABEC
```

其中：

- `D > A` 两次
- `D > B`
- `D > C`
- `E > C`

一共 `5` 个逆序对。

题目给出 `m` 个长度均为 `n` 的 DNA 字符串，需要按照逆序对数量从小到大输出。

特别注意：

> 如果两个字符串的逆序对数量相同，必须保持它们原来的输入顺序。

所以这是一个**稳定排序**问题。

---

# 二、如何计算逆序对

由于：

\[
n\le 50,\quad m\le 100
\]

直接使用两层循环已经完全足够：

```cpp
for (int i = 0; i < n; ++i)
    for (int j = i + 1; j < n; ++j)
        if (s[i] > s[j])
            ++cnt;
```

单个字符串复杂度：

\[
O(n^2)
\]

所有字符串：

\[
O(mn^2)
\]

最大也不过：

\[
100\times 50^2=250000
\]

非常小。

不过，本题字符只有：

```text
A < C < G < T
```

因此还可以做到 **O(n)** 计算一个字符串的逆序对。

---

# 三、线性统计逆序对

从左到右扫描字符串。

假设当前字符是 `C`，那么它能和左边出现过的 `G、T` 构成逆序对。

同理：

- 当前为 `A`：左边的 `C、G、T` 都产生逆序对；
- 当前为 `C`：左边的 `G、T` 产生逆序对；
- 当前为 `G`：左边的 `T` 产生逆序对；
- 当前为 `T`：不会新增逆序对。

维护四种字符已经出现的次数即可。

例如：

```cpp
int cnt[4] = {};
```

定义：

```text
A -> 0
C -> 1
G -> 2
T -> 3
```

当扫描到类别 `x` 时：

\[
\text{inv} += \sum_{j=x+1}^{3} cnt[j]
\]

然后：

```cpp
cnt[x]++;
```

因为只有 4 种字符，所以仍然可以认为是：

\[
O(n)
\]

# 四、稳定排序

我们可以保存：

```cpp
struct DNA {
    string s;
    int inv;
    int id;
};
```

其中 `id` 是原始输入顺序。

然后排序规则为：

1. `inv` 小的在前；
2. `inv` 相同时 `id` 小的在前。

这样即使使用普通 `sort`，也可以保证最终顺序符合要求。

当然，也可以直接：

```cpp
stable_sort(...)
```

只比较逆序对数量。

我更推荐保存 `id`，排序规则更加明确。

# 五、多组数据的输入输出

题目实际上采用的是类似 UVA 612 的多组输入格式：

```text
T

n m
...
```

测试用例之间可能有空行。

使用：

```cpp
cin >> T;
cin >> n >> m;
```

时，`operator>>` 会自动跳过空格和换行，所以根本不需要特殊处理空行。

输出要求：

> 两组测试数据之间输出一个空行。

因此：

```cpp
if (caseId > 0)
    cout << '\n';
```

# 七、样例分析

输入：

```text
1
10 6
AACATGAAGG
TTTTGGCCAA
TTTGGCCAAA
GATCAGATTT
CCCGGGGGGA
ATCGATGCAT
```

各字符串的逆序对数量分别为：

| 字符串 | 逆序对数 |
|---|---:|
| `AACATGAAGG` | 10 |
| `TTTTGGCCAA` | 37 |
| `TTTGGCCAAA` | 36 |
| `GATCAGATTT` | 11 |
| `CCCGGGGGGA` | 6 |
| `ATCGATGCAT` | 17 |

因此从小到大排列：

```text
CCCGGGGGGA
AACATGAAGG
GATCAGATTT
ATCGATGCAT
TTTGGCCAAA
TTTTGGCCAA
```

不过这里要特别注意：题目给出的 Sample Output 是：

```text
CCCGGGGGGA
AACATGAAGG
GATCAGATTT
ATCGATGCAT
TTTTGGCCAA
TTTGGCCAAA
```

实际上重新计算：

`TTTTGGCCAA`：

- 4 个 `T` 后面各有 `2G+2C+2A=6` 个更小字符：`24`
- 2 个 `G` 后面各有 `2C+2A=4` 个：`8`
- 2 个 `C` 后面各有 2 个 `A`：`4`

所以：

\[
24+8+4=36
\]

而 `TTTGGCCAAA`：

- 3 个 `T` 后面各有 `2G+2C+3A=7`：`21`
- 2 个 `G` 后面各有 `2C+3A=5`：`10`
- 2 个 `C` 后面各有 `3A`：`6`

所以：

\[
21+10+6=37
\]

因此正确对应应该是：

| 字符串 | 逆序对数 |
|---|---:|
| `TTTTGGCCAA` | 36 |
| `TTTGGCCAAA` | 37 |

也就恰好与 Sample Output 一致。

最终排序：

```text
CCCGGGGGGA      6
AACATGAAGG     10
GATCAGATTT     11
ATCGATGCAT     17
TTTTGGCCAA     36
TTTGGCCAAA     37
```

# 八、复杂度分析

对于每个 DNA 字符串，只扫描一次，每个位置至多检查 3 种字符：

\[
O(n)
\]

一共 `m` 个字符串：

\[
O(mn)
\]

排序 `m` 个字符串：

\[
O(m\log m)
\]

总时间复杂度：

\[
\boxed{O(mn+m\log m)}
\]

空间复杂度主要用于保存 `m` 个字符串：

\[
\boxed{O(mn)}
\]

本题最重要的两个点就是：**正确统计逆序对，以及逆序对相同时保持原输入顺序**。
