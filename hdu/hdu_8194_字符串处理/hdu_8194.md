设模式串

```text
P = "execute"
```

其中可以被修改的 `e` 位于模式串的第 `0,2,6` 位。

这题的核心不是字符串匹配，而是处理多个 `execute` 之间的重叠。

### 1. `execute` 的重叠方式非常特殊

`execute` 的非空真前缀与后缀只有：

```text
"e"
```

因此两个 `execute` 如果重叠，它们的起点只能相差 `6`：

```text
execute
      execute
```

例如样例：

```text
executexecute
^^^^^^^
      ^^^^^^^
```

所以所有 `execute` 的出现位置，可以分成若干条链：

```text
p, p+6, p+12, ..., p+6(k-1)
```

不同链之间完全不会互相影响。

---

### 2. 一条长度为 k 的链怎么修改？

定义

```text
b_j = p + 6j     (0 <= j <= k)
```

第 `j` 个 `execute` 的三个 `e` 分别位于：

```text
b_j, b_j+2, b_{j+1}
```

结构相当于：

```text
      execute
      ^ ^   ^
      b0    b1

            execute
            ^ ^   ^
            b1    b2

                  execute
                  ^     ^
                  b2    b3
```

内部的 `b_j` 可以同时破坏相邻的两个 `execute`。

因此一次修改最多消灭两个出现位置，于是至少需要

\[
\left\lceil\frac{k}{2}\right\rceil
\]

次修改。

而这个下界显然能够通过交替选择 `b_j` 达到。

#### k 为偶数

设 `k=2r`。

只允许修改 `r` 次，那么每次修改都必须同时消灭两个 `execute`。

第 0 个 `execute` 只能和第 1 个一起被消灭，所以必须修改 `b_1`；之后同理必须修改：

```text
b1, b3, b5, ...
```

即：

```cpp
p+6, p+18, p+30, ...
```

这个最优方案实际上是唯一的。

#### k 为奇数

设 `k=2r+1`。

最少需要 `r+1` 次。

由于 `'1' < 'e'`，在修改次数相同的情况下，越早的位置改成 `'1'`，整个字符串的字典序越小。

因此首先选择最左侧的：

```text
b0 = p
```

此时剩下 `2r` 个 `execute`，按照偶数情况唯一地选择：

```text
b2, b4, b6, ...
```

所以奇数长度链修改：

```text
b0, b2, b4, ...
```

---

### 3. 算法

先枚举原串中所有 `"execute"` 的起点。

注意修改 `e -> 1` 只可能破坏原来的 `"execute"`，不可能产生新的 `"execute"`，所以直接分析原串即可。

将相邻起点差为 `6` 的出现位置划入同一条链。

对于一条长度 `k`、首个起点为 `p` 的链：

- `k` 为奇数：修改 `p, p+12, p+24, ...`
- `k` 为偶数：修改 `p+6, p+18, p+30, ...`

总复杂度为 **O(|S|)**。

以第二个样例：

```text
executexecute
```

有两个重叠的 `execute`，起点为 `0,6`，链长 `k=2` 为偶数，所以修改 `b1=6`：

```text
execut1xecute
```

一次修改就同时破坏了两个 `execute`，与样例一致。
