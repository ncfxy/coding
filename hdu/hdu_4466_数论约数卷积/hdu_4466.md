这题本质上是一道 **数论 + Burnside + 约数卷积** 的题。难点主要有两个：

第一，所有三角形必须相似，因此它们一定来自同一个“最简整数三角形”；第二，需要快速计算“周长恰好为 \(d\) 的最简整数三角形有多少种”。

下面给出可以处理 \(n\le 5\times 10^6\) 的 \(O(N\log N)\) 做法。

---

## 1. 固定一个相似形状后，方案数是多少？

假设一个整数三角形的三边是

\[
(a,b,c)
\]

并且

\[
\gcd(a,b,c)=1.
\]

称它为一个**最简三角形**，周长为

\[
d=a+b+c.
\]

任何与它相似的整数三角形，都只能是

\[
(ka,kb,kc),\qquad k\in \mathbb Z_{>0}.
\]

这是因为如果缩放比例是既约分数 \(p/q\)，而三个新边长都是整数，那么 \(q\) 必须同时整除 \(a,b,c\)，而它们 gcd 为 1，所以 \(q=1\)。

假设铁丝总长是 \(n\)。如果选择这个最简形状，那么必须有

\[
d(k_1+k_2+\cdots+k_t)=n.
\]

令

\[
m=\frac nd.
\]

于是问题变成把 \(m\) 拆成若干个正整数的**有序拆分**：

\[
m=k_1+k_2+\cdots+k_t.
\]

所有正整数有序拆分的数量为

\[
2^{m-1}.
\]

因此，如果记

\[
F(d)=\text{周长为 }d\text{ 的最简整数三角形数量},
\]

那么最终答案就是

\[
\boxed{
Ans(n)=\sum_{d\mid n}F(d)\,2^{n/d-1}
}
\]

所以问题只剩下如何快速求所有 \(F(d)\)。

例如 \(n=9\)：

周长 3 有一个最简形状 \((1,1,1)\)，贡献

\[
2^{9/3-1}=4.
\]

周长 9 有两个最简形状

\[
(1,4,4),(2,3,4),
\]

各贡献 1。

所以

\[
4+2=6.
\]

正好对应样例。

# 2. 计算最简三角形数量 \(F(n)\)

三角形的三条边本质上是无序的。

我们先考虑有序三元组 \((a,b,c)\)，然后使用 Burnside 引理除掉排列造成的重复。

让 \(S_3\) 作用于三条边。

定义：

\[
A(n)=
\]

周长为 \(n\) 的、primitive 的、有序整数三角形数量。

定义

\[
B(n)=
\]

primitive 三角形中满足

\[
a=b
\]

的数量，也就是一个指定交换操作的不动点数。

定义

\[
C(n)=
\]

满足

\[
a=b=c
\]

的 primitive 三角形数量。

Burnside 得

\[
\boxed{
F(n)=\frac{A(n)+3B(n)+2C(n)}6
}
\]

因为 \(S_3\) 中有：

- 1 个恒等置换；
- 3 个交换；
- 2 个三循环。

---

# 3. 求 \(A(n)\)

先不要求 primitive。

记 \(A_0(n)\) 为所有有序整数三角形数量。

也就是

\[
a+b+c=n,\qquad
a,b,c>0
\]

并且满足三角形不等式。

经过组合计数可以得到：

当 \(n\) 为奇数：

\[
\boxed{
A_0(n)=\frac{n^2-1}{8}
}
\]

当 \(n\) 为偶数：

\[
\boxed{
A_0(n)=\frac{(n-2)(n-4)}8
}
\]

primitive 条件可以使用 Mö比乌斯反演：

\[
A(n)=\sum_{d\mid n}\mu(d)A_0(n/d).
\]

如果直接这么做，又需要一次 \(O(N\log N)\)。

可以进一步化简。

定义二阶 Jordan 函数：

\[
J_2(n)
=
n^2\prod_{p\mid n}\left(1-\frac1{p^2}\right).
\]

它满足

\[
J_2(n)=\sum_{d\mid n}\mu(d)\left(\frac nd\right)^2.
\]

同时

\[
\varphi(n)=
\sum_{d\mid n}\mu(d)\frac nd.
\]

代入上面的 \(A_0\)，可以化成：

\[
\boxed{
A(n)=
\begin{cases}
\dfrac{J_2(n)}8,
& n\text{ 为奇数},\\[6pt]
\dfrac{J_2(n)-6\varphi(n)}8,
& n\equiv0\pmod4,\\[6pt]
\dfrac{J_2(n)-12\varphi(n)}8,
& n\equiv2\pmod4,\ n>2.
\end{cases}
}
\]

\(n=1,2\) 显然没有三角形，单独处理即可。

---

# 4. 求 \(B(n)\)

现在固定

\[
a=b.
\]

三角形为

\[
(a,a,c).
\]

因为

\[
2a+c=n
\]

以及三角形条件

\[
c<2a,
\]

所以

\[
\frac n4<a<\frac n2.
\]

primitive 条件为

\[
\gcd(a,a,c)=1.
\]

因为

\[
c=n-2a,
\]

所以等价于

\[
\gcd(a,n)=1.
\]

于是 \(B(n)\) 就是在区间

\[
\left(\frac n4,\frac n2\right)
\]

中与 \(n\) 互质的整数个数。

为了在线性时间预处理它，引入模 4 Dirichlet 特征：

\[
\chi_4(n)=
\begin{cases}
0,&2\mid n,\\
1,&n\equiv1\pmod4,\\
-1,&n\equiv3\pmod4.
\end{cases}
\]

再定义

\[
H=\mu *\chi_4.
\]

则可以整理得到：

对于奇数 \(n\)：

\[
\boxed{
B(n)=\frac{\varphi(n)-H(n)}4
}
\]

如果

\[
n=2q,\qquad q\text{ 为奇数},\ n>2,
\]

那么

\[
\boxed{
B(n)=\frac{\varphi(n)+H(q)}4
}
\]

而如果

\[
4\mid n,\quad n>4,
\]

那么

\[
\boxed{
B(n)=\frac{\varphi(n)}4
}
\]

另外

\[
B(4)=0.
\]

---

## 5. 如何线性筛 \(H(n)\)

因为 \(\mu\) 与 \(\chi_4\) 都是乘法函数，所以

\[
H=\mu*\chi_4
\]

也是乘法函数。

对于素数 \(p\)：

\[
H(p)=
\begin{cases}
-1,&p=2,\\
0,&p\equiv1\pmod4,\\
-2,&p\equiv3\pmod4.
\end{cases}
\]

线性筛中，如果 \(p\nmid i\)：

\[
H(ip)=H(i)H(p).
\]

如果 \(p\mid i\)：

对于 \(p=2\) 或 \(p\equiv1\pmod4\)：

\[
H(ip)=0.
\]

对于

\[
p\equiv3\pmod4
\]

则指数增加一次，符号翻转：

\[
H(ip)=-H(i).
\]

因此 \(\varphi,J_2,H\) 三个函数都可以一次 Euler 筛求完。

# 6. \(C(n)\)

primitive 的等边三角形只有

\[
(1,1,1).
\]

所以

\[
\boxed{
C(n)=[n=3]
}
\]

最终

\[
\boxed{
F(n)=\frac{A(n)+3B(n)+2C(n)}6
}
\]

---

# 7. 最后的约数卷积

已经知道

\[
Ans(n)=
\sum_{d\mid n}
F(d)2^{n/d-1}.
\]

如果写成

\[
n=kd,
\]

那么直接枚举 \(k\)：

\[
Ans(kd)
\mathrel{+}=
F(d)2^{k-1}.
\]

代码中外层枚举 \(k\)，这样 \(2^{k-1}\) 只需要维护一次：

```text
power = 1
for k = 1..N
    for d = 1..N/k
        ans[k*d] += F[d] * power

    power *= 2
```

总循环次数为

\[
\sum_{k=1}^N\left\lfloor\frac Nk\right\rfloor
=O(N\log N).
\]

对于 \(N=5\times10^6\)，大约七八千万次，完全属于可接受范围。

## 9. 复杂度

令所有询问中的最大值为 \(N\)。

线性筛计算 \(\varphi,J_2,H\) 是

\[
O(N).
\]

Burnside 计算所有 \(F(n)\) 是

\[
O(N).
\]

最后的约数卷积是

\[
O(N\log N).
\]

因此总复杂度：

\[
\boxed{O(N\log N)}
\]

空间复杂度：

\[
\boxed{O(N)}
\]

并且代码中复用了 `phi[]` 存储 \(F(n)\)，峰值内存大约八十多 MB。
