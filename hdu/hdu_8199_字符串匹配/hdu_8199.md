这道题可以做到 **\(O(n)\) 时间、\(O(n)\) 空间**。核心是先把递归定义转换成括号串，再用括号匹配形成的“兄弟节点”结构做批量计数。

## 1. 把引号串转换成括号串

对于一个**单独的字符串** \(A\)，从 1 开始编号，定义：

- 奇数位置的 `"` → `(`
- 偶数位置的 `'` → `(`
- 其他情况 → `)`

记转换结果为 \(F(A)\)。

例如：

```text
A = ""
F = ()
```

关键结论是：

> **A 是合法引号串，当且仅当 \(F(A)\) 是合法括号串。**

原因如下。

基础情况：

```text
""  ->  ()
```

拼接情况下，因为任何合法引号串长度都是偶数，所以

\[
F(AB)=F(A)F(B)
\]

而对于第二条构造规则：

\[
A\longrightarrow "\overline A"
\]

内部字符串同时发生了两件事：

1. 字符 `'` / `"` 互换；
2. 因为最前面多了一个字符，位置奇偶也互换。

两次互换正好抵消，所以：

\[
F("\overline A")=(F(A))
\]

因此题目的递归定义正好对应合法括号串的：

\[
() ,\quad (A),\quad AB
\]

## 2. 为什么还需要处理两种括号方向？

这里有个非常容易漏掉的问题：

我们最终考察的是子串 \(s_l\dots s_r\)，而子串内部需要**重新从 1 编号**。

先按照整个字符串的下标构造括号串 \(t\)：

```text
i 为奇数：
    " -> (
    ' -> )

i 为偶数：
    ' -> (
    " -> )
```

那么：

### 当 \(l\) 为奇数

子串的局部奇偶性与全局奇偶性一致。

所以：

\[
s_l\dots s_r\text{ 合法}
\iff
t_l\dots t_r\text{ 是合法括号串}
\]

### 当 \(l\) 为偶数

局部奇偶性与全局奇偶性完全相反。

所以需要把所有括号反转：

\[
s_l\dots s_r\text{ 合法}
\iff
\overline{t_l\dots t_r}\text{ 是合法括号串}
\]

其中

```text
( <-> )
```

因此问题拆成两遍：

1. 在 \(t\) 中统计 **左端点为奇数** 的合法括号子串；
2. 在反转括号后的 \(t\) 中统计 **左端点为偶数** 的合法括号子串。

两部分答案相加即可。

# 3. 如何统计所有合法括号子串覆盖每个位置的次数？

现在考虑一个普通括号串，例如：

```text
(()())()()
```

用普通栈进行括号匹配。

每一个匹配的括号对都可以看成一个节点：

```text
( ... )
```

它的区间就是这个节点覆盖的范围。

例如：

```text
(()())()()
```

最外面的结构相当于：

```text
[ (()()) ] [ () ] [ () ]
```

这三个是同一层的兄弟节点。

一个非常重要的性质是：

> 任意合法括号子串，一定恰好是某一层中若干个**连续兄弟节点**的拼接。

反过来也成立。

例如同一组兄弟：

\[
v_1,v_2,\dots,v_m
\]

那么：

```text
v1
v2
v1v2
v2v3
v1v2v3
...
```

只要选择连续的一段，都是合法括号串。

# 4. 对一个节点计算贡献

设某一兄弟组有：

\[
v_1,v_2,\dots,v_m
\]

现在考虑第 \(x\) 个节点 \(v_x\)。

我们想知道有多少合法括号子串：

1. 包含 \(v_x\)；
2. 左端点满足要求的奇偶性。

一个合法子串对应：

\[
v_a v_{a+1}\dots v_b
\]

并且：

\[
a\le x\le b
\]

设前 \(x\) 个节点中，有 \(E_x\) 个节点的左端点奇偶性满足要求。

那么：

- 左端 \(a\)：有 \(E_x\) 种选择；
- 右端 \(b\)：可以取 \(x,x+1,\dots,m\)，共

\[
m-x+1
\]

种。

因此覆盖节点 \(v_x\) 的合法子串数量为：

\[
\boxed{E_x(m-x+1)}
\]

而只要一个合法子串选择了节点 \(v_x\)，它就会覆盖 \(v_x\) 的整个匹配区间。

因此我们只需要给 \(v_x\) 的区间：

\[
[L_x,R_x]
\]

整体增加

\[
E_x(m-x+1)
\]

使用差分数组即可做到 \(O(1)\) 区间加。

# 5. 不需要真的建树

显式建立括号树也没必要。

做两遍扫描即可。

### 第一遍

用栈匹配括号。

对于每个匹配的左括号 \(L\)，记录：

```text
match[L] = R
```

同时统计它所在兄弟组一共有多少个匹配节点，即 \(m\)。

兄弟组可以用它的直接父左括号作为编号。

对于最外层，需要注意：

```text
() ) ()
   ^
```

未匹配右括号显然不能被合法括号串跨过去，因此每遇到一个最外层未匹配右括号，就开启新的根兄弟组。

---

### 第二遍

再次从左到右扫描。

对于当前兄弟组维护：

```text
seen[g]
```

表示已经遇到多少个“左端点奇偶合法”的兄弟节点。

同时第一遍得到的：

```text
remain[g]
```

一开始等于 \(m\)。

处理第 \(x\) 个兄弟时：

```text
remain[g] = m-x+1
```

所以：

```cpp
weight = seen[g] * remain[g];
```

然后：

```cpp
--remain[g];
```

把 `weight` 区间加到当前节点的匹配区间即可。

# 6. 复杂度

整个过程执行两次：

- 原括号串 + 奇数左端点；
- 括号取反 + 偶数左端点。

每次只需要常数遍线性扫描。

所以：

\[
\boxed{O(n)}
\]

空间：

\[
\boxed{O(n)}
\]

\(n\le10^6\) 完全可以通过。

答案可能达到 \(O(n^2)\)，必须使用 `long long`。

这道题最核心的两个观察就是：

\[
\boxed{\text{引号递归结构}\Longleftrightarrow\text{括号结构}}
\]

以及

\[
\boxed{\text{合法括号子串}
=\text{一组连续的兄弟匹配节点}}
\]

第二个观察使得原本可能有 \(O(n^2)\) 个合法子串，可以通过每个匹配节点一次区间加，在线性时间内统计所有位置的答案。
