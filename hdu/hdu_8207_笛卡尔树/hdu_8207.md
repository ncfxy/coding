# 题目解析

设一次分配后的增量为 `x1, x2, ..., xn`，满足：

\[
x_i\ge 0,\qquad \sum x_i=p
\]

记 `F(b)` 为数组 `b` 的所有子数组最大值之和。

## 为什么钱全存一张卡一定最优

对第 `i` 张卡，定义方案：

\[
B^{(i)}=a+p\cdot e_i
\]

即把全部 `p` 刀都存进第 `i` 张卡。

对于任意一种分配 `x`，当 `p>0` 时令：

\[
\lambda_i=\frac{x_i}{p}
\]

显然：

\[
\lambda_i\ge 0,\qquad \sum\lambda_i=1
\]

并且分配后的数组可以写为：

\[
a+x=\sum_{i=1}^{n}\lambda_i B^{(i)}
\]

考虑一个固定区间 `[l,r]`。`max` 函数是凸函数，因此：

\[
\max_{l\le k\le r}(a_k+x_k)
\le
\sum_{i=1}^{n}\lambda_i
\max_{l\le k\le r}B_k^{(i)}
\]

对所有区间求和：

\[
F(a+x)
\le
\sum_{i=1}^{n}\lambda_i F(B^{(i)})
\le
\max_i F(B^{(i)})
\]

因此，任何“分散存钱”的方案都不会优于“把所有钱存进某一张卡”的最佳方案。

所以每个询问只需枚举：

\[
\max_{1\le i\le n}F(a+p\cdot e_i)
\]

`p=0` 时显然也成立。

## 代码如何计算

### 1. 用最大笛卡尔树求原始答案

最大笛卡尔树满足：

- 中序遍历顺序就是原数组下标顺序；
- 父节点的余额不小于子节点；
- 相同余额时，代码按下标打破平局，保证每个区间只归属于一个“最大值位置”。

若节点 `u` 的左、右子树大小分别为 `ls[u]`、`rs[u]`，那么以 `u` 为唯一代表最大值的子数组数量为：

\[
(ls[u]+1)(rs[u]+1)
\]

因此原数组的答案是：

\[
base=\sum_u a_u(ls[u]+1)(rs[u]+1)
\]

对应代码：

```cpp
base += a[i] * (ls[i] + 1) * (rs[i] + 1);
```

---

### 2. 固定向 `pos` 存钱时，增量如何计算

令：

\[
b=a_{pos}+p
\]

只有包含 `pos` 的子数组会发生变化。若原区间最大值为 `M`，它的增量是：

\[
\max(0,b-M)
\]

所以总增量为：

\[
D_{pos}(p)=
\sum_{L\le pos\le R}
\max(0,a_{pos}+p-\max(a_L,\dots,a_R))
\]

当 `b` 再增加 `1` 时，哪些区间的答案也会增加 `1`？

恰好是原区间最大值小于 `b` 的区间。也就是说，区间内所有元素都小于 `b`。

若在原数组中，包含 `pos` 且所有值 `< b` 的极大连续段为 `[L,R]`，那么可选子数组数为：

\[
(pos-L+1)(R-pos+1)
\]

这就是当前 `Dpos(p)` 的斜率。

---

### 3. 笛卡尔树如何得到这些斜率

随着 `pos` 的余额不断增加，它会依次超过笛卡尔树中从自己到根的祖先高度。

当它超过某个祖先 `top` 的余额后，能够被它“覆盖”的连续区间，正好是 `top` 子树对应的中序区间：

```cpp
ll L = top - ls[top];
ll R = top + rs[top];
```

此时斜率为：

```cpp
ll slope = (pos - L + 1) * (R - pos + 1);
```

代码把这些“余额跨过某个高度后，斜率变成多少”的信息保存成：

```cpp
events.push_back({h - a[pos], slope});
```

其中：

- `h - a[pos]`：需要存多少钱才会跨过高度 `h`；
- `slope`：跨过后，每多存 `1` 刀带来的答案增长。

相同高度的祖先必须合并处理：

```cpp
while (u != -1 && a[u] == h) {
    top = u;
    u = parent[u];
}
```

因为余额从 `h` 增加到 `h+1` 时，所有原本等于 `h` 的位置会同时变成“小于新余额”，不能错误地分成多次扩张。

---

### 4. 为什么要将询问排序

对一个固定的 `pos`，`Dpos(p)` 是分段一次函数。

例如事件可能是：

| `p` 范围 | 斜率 |
|---|---:|
| `[0, 3]` | 2 |
| `[3, 8]` | 6 |
| `[8, +∞)` | 12 |

将询问按 `p` 从小到大排序后，可以用一个指针扫过事件：

```cpp
while (ptr < events.size() && events[ptr].first <= nowP) {
    currentValue += slope * (nextP - lastP);
    lastP = nextP;
    slope = events[ptr].second;
    ++ptr;
}
```

其中：

- `currentValue` 是 `Dpos(lastP)`；
- `slope` 是当前分段的斜率；
- 当前询问的增量为：

```cpp
ll gain = currentValue + slope * (nowP - lastP);
```

最后枚举所有 `pos`：

```cpp
ans[id] = max(ans[id], base + gain);
```

即得到“把全部 `p` 存到哪张卡最优”的答案。

---

总复杂度为：

\[
O(n^2+nq+q\log q)
\]

空间复杂度为：

\[
O(n+q)
\]

其中 `n²` 来自枚举每个位置并向笛卡尔树根部走祖先链，`nq` 来自每张卡扫一遍全部询问。
