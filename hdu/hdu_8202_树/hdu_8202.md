# HDU 8202 题解

## 题目在算什么

一棵 \(n\) 个点的树（代码里以 \(1\) 为根），每个点有权值 \(a_i\)。

对树上任意三个**互不相同**的点 \(x,y,z\)，看它们的三对两两 LCA：

\[
\operatorname{LCA}(x,y),\quad \operatorname{LCA}(y,z),\quad \operatorname{LCA}(z,x)
\]

若这三个 LCA **全部等于同一个点** \(v\)，则这个三元组贡献 \(a_x\cdot a_y\cdot a_z\)。

答案是所有合法三元组贡献之和，对 \(998244353\) 取模。

---

## 关键观察：合法三元组长什么样

固定一个点 \(v\)，问：哪些三元组的三对 LCA 都恰好是 \(v\)？

把树以 \(1\) 为根后，在 \(v\) 处把整棵树切成若干「组」：

| 组 | 包含哪些点 | 组和（权值和） |
|---|---|---|
| 组 \(0\) | 只有 \(v\) 自己 | \(a_v\) |
| 组 \(1\) | \(v\) 的第 \(1\) 个儿子整棵子树 | 该子树所有 \(a_i\) 之和 |
| 组 \(2\) | \(v\) 的第 \(2\) 个儿子整棵子树 | … |
| … | … | … |

注意：这里**没有**「\(v\) 上方」那一块。因为若某个点在 \(v\) 的祖先方向，它和 \(v\) 子树里某点的 LCA 会是 \(v\) 的某个祖先，不可能三对 LCA 都停在 \(v\)。

**结论：**

三个点 \(x,y,z\) 的三对 LCA 都等于 \(v\)，当且仅当它们分别来自上述**三个不同的组**。

直观理解：

- 若两点落在同一儿子子树里，它们的 LCA 在该子树内部，严格深于 \(v\)；
- 若两点来自不同儿子子树，或其中一点是 \(v\)，它们的 LCA 恰好是 \(v\)；
- 因此要三对 LCA 都是 \(v\)，三点必须两两不在同一组，即分属三个组。

于是，节点 \(v\) 对答案的贡献就是：

\[
\sum_{\text{三个不同的组 } g_1,g_2,g_3}
\Bigl(\sum_{i\in g_1}a_i\Bigr)
\Bigl(\sum_{j\in g_2}a_j\Bigr)
\Bigl(\sum_{k\in g_3}a_k\Bigr)
\]

把所有节点 \(v\) 的贡献加起来，就是总答案（每个合法三元组恰好在其「公共 LCA」那一层被统计一次）。

## 小例子

```
      1 (a=1)
     / \
  2(a=2) 3(a=3)
         / \
      4(a=4) 5(a=5)
```

看 \(v=3\) 的组：

- 组 \(0\)：\(\{3\}\)，和 \(=3\)
- 组 \(1\)：\(\{4\}\)，和 \(=4\)
- 组 \(2\)：\(\{5\}\)，和 \(=5\)

只有一组三个组：贡献 \(3\cdot 4\cdot 5=60\)，对应三元组 \(\{3,4,5\}\)。  
确实 \(\operatorname{LCA}(3,4)=\operatorname{LCA}(3,5)=\operatorname{LCA}(4,5)=3\)。

再看 \(v=1\) 的组：

- 组 \(0\)：\(\{1\}\)，和 \(=1\)
- 组 \(1\)：\(\{2\}\)，和 \(=2\)
- 组 \(2\)：\(\{3,4,5\}\)，和 \(=3+4+5=12\)

贡献 \(1\cdot 2\cdot 12=24\)，展开后对应三元组 \(\{1,2,3\},\{1,2,4\},\{1,2,5\}\)。  
例如 \(\{1,2,4\}\)：三对 LCA 都是 \(1\)，合法；\(\{2,4,5\}\) 的 LCA 分别是 \(1,3,1\)，不全相同，不会算进 \(v=1\)，也不会算进 \(v=3\)（因为 \(2\) 不在 \(3\) 的组里）。

## 怎么快速算「各组和的三元乘积和」

设 \(v\) 处各组和为 \(x_0,x_1,\dots,x_m\)（\(x_0=a_v\)，其余是各儿子子树和）。

要求：

\[
s_3=\sum_{0\le i<j<k\le m} x_i\,x_j\,x_k
\]

暴力枚举三个组是 \(O(\deg(v)^3)\)，太慢。用增量维护：

依次把每个组和 \(x\) 加进来，维护三个量：

| 变量 | 含义 |
|---|---|
| `s1` | 已处理各组之和 \(\sum x_i\) |
| `s2` | 已处理组里任选两个不同组的乘积和 \(\sum_{i<j}x_i x_j\) |
| `s3` | 已处理组里任选三个不同组的乘积和 \(\sum_{i<j<k}x_i x_j x_k\) |

新加入一个组和 \(x\) 时，所有「包含这个新组」的新三项积，等于「旧的两项积」再乘 \(x\)：

```cpp
s3 += s2 * x;   // 旧两项积 × 新组 = 新的三项积
s2 += s1 * x;   // 旧一项和 × 新组 = 新的两项积
s1 += x;        // 把新组加进总和
```

**顺序不能乱**：必须先更新 `s3`，再 `s2`，再 `s1`，否则会用到已经混入新组的值。

处理完所有组后，`s3` 就是 \(v\) 的贡献。

同时，`s1` 恰好等于「以 \(v\) 为根的子树权值和」，可以留给父亲当「一个组和」用：

```cpp
subtreeSum[v] = s1;
```

## 和代码的对应关系

1. **建树 + 非递归 DFS 求 DFS 序**  
   得到 `order` 和 `parent`。用栈模拟是为了避免树退化成链时递归爆栈。

2. **按 `order` 逆序处理**  
   保证处理 \(v\) 时，所有儿子的 `subtreeSum` 已经算好。

3. **在每个 \(v\) 上跑上面的增量**  
   - 初始：`s1 = a[v]`（先放进「自己」这一组），`s2 = s3 = 0`  
   - 再依次加入每个儿子的 `subtreeSum[u]`  
   - `ans += s3`，`subtreeSum[v] = s1`

整棵树每个点、每条边只被扫常数次，总复杂度 \(O(n)\)，空间 \(O(n)\)。

---

## 小结

1. 按「三对 LCA 的公共点」拆答案：每个 \(v\) 独立贡献。  
2. \(v\) 处合法三元组 = 从「自己 + 各儿子子树」这些组里选三个不同组，各取一点。  
3. 贡献等于组和的三元乘积和；用 `s1/s2/s3` 增量在 \(O(\deg(v))\) 内算完。  
4. 子树和顺便在同一次自底向上遍历里求出。
