这道题的关键是把 **白色格子 `W` 当成“重置点”**。最终可以做到 **O(|s|)** 解决每组数据，总复杂度 \(O(\sum |s|)\)。

## 1. 白格为什么能把问题分段？

题目允许从第 \(i\) 格跳到第 \(j\) 格，其中

\[
i\le j
\]

特别地，角色站在白格时，可以执行

\[
i\to i
\]

原地跳跃。白格 Mutsumi 和 Mortis 都能跳，所以可以通过原地跳一次来切换当前操纵者。

因此，在任意白格上，我们都可以自由决定：

> 接下来离开这个白格时，由 Mutsumi 还是 Mortis 操纵。

所以两个白格之间的红黑格，与其他区间基本独立。

例如

```text
RRBRB W BRR W RBB
```

可以拆成

```text
RRBRB
BRR
RBB
```

分别计算。

最终答案就是所有连续 `R/B` 段所需轮数的最大值。

---

## 2. 一个纯 R/B 段，一轮能走什么样的格子？

假设一轮里经过若干有色格子。

Mutsumi 只能跳到 `R`，Mortis 只能跳到 `B`，并且每跳一次都会换人。

所以同一轮经过的有色格子的颜色一定形如：

```text
R B R B R ...
```

或者

```text
B R B R B ...
```

由于前面的白格可以调整当前玩家，所以两种开头都可以。

而跳跃可以跳过任意中间格子，因此：

> 一轮对应原字符串的一个“颜色交替子序列”。

于是问题变成：

> 把一个只含 `R/B` 的字符串，划分成最少数量的交替子序列。

注意每个红黑格只能被一轮经过，所以每个字符恰好分配给一个子序列。

---

# 3. 如何最少划分成交替子序列？

维护：

- `r`：当前有多少条子序列以 `R` 结尾；
- `b`：当前有多少条子序列以 `B` 结尾；
- `cnt = r+b`：当前使用了多少轮。

从左到右处理。

### 遇到 `R`

如果有某条序列以 `B` 结尾：

```text
...B + R
```

直接接上去，不需要新增一轮：

```cpp
b--;
r++;
```

如果没有任何序列以 `B` 结尾，那么这个 `R` 不可能接在已有的 `R` 后面，只能新开一轮：

```cpp
r++;
cnt++;
```

### 遇到 `B`

完全对称：

```cpp
if (r > 0) {
    r--;
    b++;
} else {
    b++;
    cnt++;
}
```

---

## 4. 为什么这个贪心是对的？

考虑当前字符为 `R`。

它只能接在一个以 `B` 结尾的交替子序列后面。

如果存在这样的子序列，那么把当前 `R` 接上：

```text
... B R
```

不增加子序列数量。

如果不存在，那么所有已有子序列都以 `R` 结尾：

```text
...R
...R
...R
```

当前 `R` 不可能放进其中任何一条，所以 **无论采用什么方案都必须新建一条子序列**。

`B` 同理。

因此每一次新建都是被迫的，贪心得到的就是最少轮数。

---

# 5. 不同红黑段为什么取最大值而不是求和？

例如：

```text
RRR W BBB
```

第一段需要 3 轮，第二段也需要 3 轮。

但答案不是 6。

我们可以使用同样的三轮：

```text
第1轮：第一段一个 R → W → 第二段一个 B
第2轮：第一段一个 R → W → 第二段一个 B
第3轮：第一段一个 R → W → 第二段一个 B
```

到了 `W` 后可以通过原地跳调整操纵者。

所以如果每一段分别需要

\[
k_1,k_2,\dots
\]

轮，只需要准备

\[
K=\max k_i
\]

轮即可。

每一段把它自己的交替子序列任意对应到这 \(K\) 轮中的若干轮。

---

# 6. 白格本身怎么办？

白格可以被多轮重复经过，没有限制。

只需要让其中任意一轮依次经过所有白格即可。

如果整个字符串全是 `W`，虽然没有红黑格，但仍然至少需要进行一轮游戏才能经过这些格子。

因此最终：

\[
\boxed{\text{ans}=\max(1,\max_{\text{每个 RB 段}}\text{need(segment)})}
\]

---

## 7. 样例

```text
RRBWRB
```

分成两段：

```text
RRB
RB
```

### 第一段 `RRB`

初始

```text
r=0,b=0,cnt=0
```

第一个 `R`：

```text
没有 B 结尾
=> 新开
r=1,b=0,cnt=1
```

第二个 `R`：

```text
仍没有 B 结尾
=> 新开
r=2,b=0,cnt=2
```

`B`：

```text
找到 R 结尾
=> 接上
r=1,b=1,cnt=2
```

所以第一段需要 `2` 轮。

可以划分：

```text
R B
R
```

第二段 `RB` 只需要 `1` 轮。

因此

\[
\boxed{\max(2,1)=2}
\]

与样例一致。

# 8. C++ 实现

## 复杂度

每个字符只处理一次：

\[
O(|s|)
\]

所有测试数据满足

\[
\sum |s|\le 2\times10^6
\]

所以总时间复杂度：

\[
\boxed{O\left(\sum |s|\right)}
\]

额外空间：

\[
\boxed{O(1)}
\]

核心结论可以浓缩为一句话：**`W` 将问题分成独立区间；每个 `R/B` 区间求“最少交替子序列覆盖数”，再对所有区间取最大值。**
