设初始炮左边、右边的马数分别为

\[
L=k-1,\qquad R=n-k.
\]

这道题最关键的一步，是完全不需要关心每匹马具体在哪个格子，只需要关心炮左右各有多少匹马。

### 1. 一次操作对 \((L,R)\) 的影响

假设炮向左吃马。

它必须越过恰好一匹马 \(B\)，吃掉第二匹马 \(A\)，然后炮移动到 \(A\) 的位置。

因此：

- 原来左边的两匹马中，\(A\) 被吃掉；
- \(B\) 会跑到新炮位置的右边。

所以

\[
(L,R)\to(L-2,R+1).
\]

前提是 \(L\ge 2\)。

同理，向右：

\[
(L,R)\to(L+1,R-2),
\]

前提是 \(R\ge2\)。

于是棋盘问题变成了一个纯粹的二维整数问题。

---

## 2. 假设向左、向右分别走了 \(x,y\) 次

最终左右马数为

\[
L'=L-2x+y,
\]

\[
R'=R+x-2y.
\]

需要满足

\[
L'\ge0,\qquad R'\ge0.
\]

同时，每次操作都会吃掉一匹马，因此

\[
L'+R'=L+R-x-y.
\]

特别注意：如果一开始有马，那么最终不可能变成 \((0,0)\)。

因为要吃最后一匹马时，棋盘上已经不存在另一匹马作为“炮架”了。

---

## 3. 这些条件是否也充分？

是的。

也就是说，只要

\[
x,y\ge0,
\]

\[
L-2x+y\ge0,
\]

\[
R+x-2y\ge0,
\]

并且最终不是 \((0,0)\)，就一定存在某种操作顺序实现它。

证明可以用归纳。

如果只剩一种方向的操作，那么最终非负条件已经保证这种操作可以连续执行。

如果左右操作都还剩，并且当前既不能向左也不能向右，那么

\[
L\le1,\qquad R\le1.
\]

但此时至少还需要两次操作，因此最终马数

\[
L+R-x-y\le 0.
\]

由于最终马数不能为负，只可能恰好变成 \(0\)，即最终状态是 \((0,0)\)，这正是我们排除的唯一情况。

所以除此之外一定至少有一种需要执行的操作当前是合法的，归纳即可。

---

# 4. 把价值也写成 \(x,y\)

初始价值是

\[
V_0=uL+vR.
\]

向左一次：

\[
(L,R)\to(L-2,R+1),
\]

价值变化

\[
a=v-2u.
\]

向右一次价值变化

\[
b=u-2v.
\]

所以

\[
V=V_0+ax+by.
\]

我们要求这个式子的最小值。

---

# 5. 固定 \(x\)，求 \(y\) 的合法范围

由

\[
L-2x+y\ge0
\]

得到

\[
y\ge2x-L.
\]

同时 \(y\ge0\)，所以

\[
y_{\min}=\max(0,2x-L).
\]

由

\[
R+x-2y\ge0
\]

得到

\[
y\le \left\lfloor\frac{R+x}{2}\right\rfloor.
\]

因此

\[
y_{\max}=\left\lfloor\frac{R+x}{2}\right\rfloor.
\]

存在合法 \(y\) 当且仅当

\[
0\le x\le
X=\left\lfloor\frac{2L+R}{3}\right\rfloor.
\]

所以现在只剩下在 \(x\in[0,X]\) 中找最优点。

---

# 6. 根据 \(b=u-2v\) 分类

对于固定 \(x\)，

\[
V=V_0+ax+by.
\]

### 情况一：\(b\ge0\)

此时 \(y\) 越小越好，所以一定取

\[
y=\max(0,2x-L).
\]

令

\[
q=\left\lfloor\frac L2\right\rfloor.
\]

当 \(x\le q\)：

\[
y=0,
\]

因此目标函数关于 \(x\) 是线性的。

当 \(x\ge q+1\)：

\[
y=2x-L,
\]

目标函数仍然关于 \(x\) 线性。

因此只需要检查两个线性区间的端点：

\[
0,\quad \min(X,q),\quad q+1,\quad X.
\]

如果 \(X\) 对应非法的最终 \((0,0)\)，还需要检查紧邻它的 \(X-1\)。

---

### 情况二：\(b<0\)

此时 \(y\) 越大越好：

\[
y=\left\lfloor\frac{R+x}{2}\right\rfloor.
\]

目标函数变成

\[
V=V_0+ax+b\left\lfloor\frac{R+x}{2}\right\rfloor.
\]

由于存在除以 \(2\) 的下取整，我们分别考虑 \(x\) 的奇偶性。

对于相同奇偶性的 \(x\)，令 \(x\to x+2\)，价值变化恒为

\[
2a+b.
\]

所以每一种奇偶性的序列都是单调的，只需要检查它的两端。

因此检查

\[
0,1,X,X-1
\]

即可。

为了处理端点刚好是不可达到的 \((0,0)\)，再检查 \(X-2,X-3\) 即可。

总共只有常数个候选状态。

---

## C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

using int64 = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        int64 n, k, u, v;
        cin >> n >> k >> u >> v;

        int64 L = k - 1;
        int64 R = n - k;

        // n = 1，没有任何马
        if (L + R == 0) {
            cout << 0 << '\n';
            continue;
        }

        // 向左一次、向右一次造成的价值变化
        int64 a = v - 2 * u;
        int64 b = u - 2 * v;

        // x 的最大可能值
        int64 X = (2 * L + R) / 3;

        vector<int64> cand;

        if (b >= 0) {
            int64 q = L / 2;

            cand.push_back(0);
            cand.push_back(min(X, q));

            if (q + 1 <= X)
                cand.push_back(q + 1);

            cand.push_back(X);
            cand.push_back(X - 1);
        } else {
            // 每一种奇偶性的 x 都是单调的
            cand.push_back(0);
            cand.push_back(1);

            cand.push_back(X);
            cand.push_back(X - 1);

            // 防止 X 或相邻端点恰好对应最终 (0,0)
            cand.push_back(X - 2);
            cand.push_back(X - 3);
        }

        int64 ans = LLONG_MAX;

        for (int64 x : cand) {
            if (x < 0 || x > X)
                continue;

            int64 low = max<int64>(0, 2 * x - L);
            int64 high = (R + x) / 2;

            if (low > high)
                continue;

            int64 y;

            if (b >= 0)
                y = low;
            else
                y = high;

            int64 finalL = L - 2 * x + y;
            int64 finalR = R + x - 2 * y;

            if (finalL < 0 || finalR < 0)
                continue;

            // 初始有马时，不可能把所有马全部吃光
            if (finalL == 0 && finalR == 0)
                continue;

            int64 value = u * finalL + v * finalR;
            ans = min(ans, value);
        }

        cout << ans << '\n';
    }

    return 0;
}
```

### 复杂度

每组数据只检查常数个候选状态：

\[
\boxed{O(1)}
\]

总复杂度

\[
\boxed{O(T)}
\]

空间复杂度

\[
\boxed{O(1)}.
\]

样例中第三组 \(L=2,R=1,u=100,v=1\)，直接向左吃一次后变成 \((0,2)\)，价值从 \(201\) 降到 \(2\)，正好得到样例答案。
