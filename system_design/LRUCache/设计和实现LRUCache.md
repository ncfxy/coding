# 问题

设计和实现 LRUCache 

# 设计思路

1. **数据结构选择**  
   - **哈希表** 实现 O(1) 的 `get` 和 `put` 定位。  
   - **双向链表**维护访问顺序：头部为最近使用，尾部为最久未使用。  
   - 使用**虚拟头尾节点**简化边界操作，避免空指针判断。

2. **核心操作**  
   - `get(key)`：若存在，将对应节点移至链表头部并返回 value；否则返回 -1。  
   - `put(key, value)`：  
     - 若 key 已存在，更新值并移至头部；  
     - 若不存在，新建节点插入头部，若超过容量则删除尾部节点并清除哈希表记录。

3. **内存管理**  
   - 使用裸指针动态分配节点，析构函数释放所有节点，避免内存泄漏。

4. **复杂度**  
   - 时间：`get` 和 `put` 均为 O(1)（哈希表 + 链表指针操作）。  
   - 空间：O(capacity)，存储缓存中的所有键值对。
