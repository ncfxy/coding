# 线段树

**线段树（Segment Tree）是一种基于分治思想的二叉树数据结构**，主要用于高效地维护和查询一个数组的**区间信息**。它能够在对数级时间复杂度 \(O(\log n)\) 内完成区间查询和修改操作。

### 💡 核心思想与结构
线段树的核心思想是**分治**。它将一个数组的区间不断对半分割，直到每个子区间只包含单个元素，从而形成一棵树。

*   **根节点**：代表整个数组区间。
*   **内部节点**：代表其对应区间的一半（左子节点为左半区间，右子节点为右半区间）。
*   **叶子节点**：代表数组中的单个元素。

每个节点都会存储其对应区间的**聚合信息**，例如区间和、最大值、最小值等。

### 🚀 核心操作与复杂度
线段树的强大之处在于其所有核心操作的时间复杂度都是 \(O(\log n)\)，这比直接操作数组的 \(O(n)\) 要快得多。

*   **建树 (Build)**：从叶子节点开始，逐层向上合并子节点信息，构建整棵树，时间复杂度为 **\(O(n)\)**。
*   **单点更新 (Point Update)**：从根节点出发，找到目标叶子节点并更新，然后在回溯时更新所有受影响的祖先节点。
*   **区间查询 (Range Query)**：从根节点开始，如果当前节点区间被完全包含在查询区间内，则直接返回该节点的信息；否则，递归查询其子节点。
*   **区间更新 (Range Update)**：这是线段树最核心的优势之一。为了高效更新整个区间，它引入了 **“懒标记” (Lazy Tag)** 技术。更新时，只对完全被覆盖的节点进行标记和更新，而不立即更新其所有子孙节点，从而将区间更新的复杂度也降至 **\(O(\log n)\)**。

### 🎯 主要应用场景
线段树非常适合处理需要**动态修改**和**频繁区间查询**的场景：

*   **区间求和**：快速计算数组中任意连续子数组的和。
*   **区间最值**：快速查询任意区间内的最大值或最小值（RMQ问题）。
*   **区间染色/覆盖**：维护一个区间被覆盖的状态或次数。
*   **其他复杂统计**：如区间最大子段和、区间内不同元素的个数等。

### 📝 简单总结
线段树是一种功能强大、应用广泛的数据结构，其**核心优势在于能够以 \(O(\log n)\) 的高效率处理动态数组的区间查询和修改问题**。虽然其实现相比普通数组操作更复杂，但在处理大规模数据时，性能优势非常明显，是算法竞赛和工程实践中解决区间问题的利器。

## 典型应用场景

### 1. 区间最值查询（RMQ）
查询任意区间 \([l, r]\) 的最大值或最小值。典型题目如洛谷 P1198 `[JSOI2008]最大数`。

### 2. 区间求和与动态修改
维护一个数组，支持单点修改 + 区间求和，或区间修改 + 区间求和。典型题目如洛谷 P3372 `【模板】线段树 1`。

### 3. 区间染色/覆盖问题
维护区间被覆盖的状态，支持区间赋值和查询可见颜色数量。如一面墙反复涂色，最终查询有多少种颜色可见。

### 4. 区间最大子段和
每个节点维护四个值：区间和、前缀最大值、后缀最大值、最大子段和，支持单点修改和区间查询。

### 5. 区间翻转（01序列）
维护 01 序列的区间翻转操作，每个节点记录区间内 1 的个数和懒标记。典型题目如 LeetCode 2569。

### 6. 扫描线算法
用于计算矩形面积并、周长并等问题。将矩形按 x 坐标排序，用线段树维护当前被覆盖的 y 轴区间长度。

### 7. 线段树分治
将时间维度的区间操作转化为线段树上的离线处理，配合可撤销并查集等数据结构。

### 8. 维护复杂区间信息
- **区间内不同元素个数**
- **区间内第 k 大的数**
- **区间内连续空位的最长长度**（如酒店房间分配问题）
- **多个懒标记组合**：同时支持区间加、区间乘、区间赋值等操作

### 9. 实际工程应用
- **数据库索引**：用于范围查询和索引数据
- **空间搜索**：多维空间中的碰撞检测
- **编译器**：语法分析和优化

## 五、注意事项

| 要点 | 说明 |
|------|------|
| **数组开4倍** | 线段树用数组存储，需开 `4 * n` 空间 |
| **懒标记下放** | 区间修改/查询进入子节点前，**必须先 `pushdown`** 当前节点的懒标记 |
| **递归深度** | 线段树深度约 \(\log n\)，一般不会栈溢出 |
| **合并操作** | 修改 `pushup` 逻辑即可适配求和、最大值、最小值、按位与等不同统计需求 |
| **懒标记前提** | 修改操作必须能在 \(O(1)\) 内根据区间长度计算出更新后的区间信息 |
