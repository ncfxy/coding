
# 笛卡尔树（Cartesian Tree）完全指南

笛卡尔树是一种巧妙融合了**二叉搜索树（BST）**和**堆（Heap）**性质的二叉树数据结构。它能从普通数组中**线性时间**构建，并能优雅地解决范围最值查询（RMQ）、最大子矩形等经典问题。

---

## 1. 核心定义

对于给定的序列 `A[1..n]`，其笛卡尔树由 `n` 个节点构成，每个节点对应一个数组元素。树同时满足：

- **二叉搜索树性质**：树的中序遍历顺序等于原数组的顺序（即下标从小到大）。
- **堆性质**：每个节点的值（或优先级）大于（大根堆）或小于（小根堆）其所有子节点的值。

当序列元素**互不相同**时，笛卡尔树的结构是**唯一**的。若有重复值，可通过附加下标作为第二关键字来打破平局。

---

## 2. 关键直观理解（最重要）

> **任何一个节点，其子树所覆盖的节点集合，恰好对应原数组中的一个连续区间；并且该节点就是这个区间内的最小值（小根堆）或最大值（大根堆）。**

换句话说，每个节点“管辖”了一段连续子数组，而自己就是这段区间里的最值。这一性质是所有应用的根本。

---

## 3. 构建方法：单调栈（O(n)）

采用**单调栈**维护当前树的最右链（从根一直向右的路径）。算法依次插入每个新节点，并维护堆性质。

### 伪代码（小根堆示例）

```python
def build_cartesian_tree(A):
    n = len(A)
    parent = [0]*(n+1)   # 可选，记录父节点
    left = [0]*(n+1)     # 左孩子
    right = [0]*(n+1)    # 右孩子
    stack = []           # 存储下标，栈内值单调递增（小根堆）

    for i in range(1, n+1):
        last = 0
        # 弹出所有值大于 A[i] 的节点
        while stack and A[stack[-1]] > A[i]:
            last = stack.pop()
        if stack:
            # 当前节点成为栈顶的右孩子
            right[stack[-1]] = i
            parent[i] = stack[-1]
        if last:
            # 被弹出的最后一个节点成为当前节点的左孩子
            left[i] = last
            parent[last] = i
        stack.append(i)

    root = stack[0]  # 栈底即为根节点
    return root, left, right
```

### 手动图解示例（数组 `[3, 1, 4, 2]`）

| 步骤 | 当前元素 | 操作 | 栈状态（下标:值） | 树结构变化 |
|------|----------|------|-------------------|------------|
| 1    | 3        | 入栈 | [1:3]             | 根:3       |
| 2    | 1        | 弹出3，3成为1的左孩子，1入栈 | [2:1] | 1->左=3，根变为1 |
| 3    | 4        | 不弹出，4成为1的右孩子，4入栈 | [2:1, 3:4] | 1->右=4 |
| 4    | 2        | 弹出4，4成为2的左孩子；栈顶1小于2，2成为1的右孩子，2入栈 | [2:1, 4:2] | 1->右=2，2->左=4 |

最终树：
```
        1
       / \
      3   2
         /
        4
```

## 4. 主要应用场景

### 4.1 范围最值查询（RMQ）

**问题**：多次询问数组任意区间 `[L, R]` 的最小（大）值。

**解法**：构建笛卡尔树（小根堆）后，区间 `[L, R]` 的最小值就是**节点 L 和节点 R 的最近公共祖先（LCA）**所代表的值。预处理 LCA（如倍增或 Tarjan），单次查询 O(log n) 甚至 O(1)（配合 ±1 RMQ）。

### 4.2 最大子矩形（柱状图最大矩形面积，LeetCode 84）

**问题**：给定高度数组，求能组成的最大矩形面积。

**解法**：构建小根笛卡尔树。对于每个节点 `u`，其子树覆盖的区间宽度 `width = right_span[u] - left_span[u] + 1`，则以 `A[u]` 为高的最大面积为 `A[u] * width`。遍历所有节点取最大值即可。

### 4.3 与 Treap 的关系

Treap 是一种平衡树，其键值满足 BST，优先级满足堆性质。**笛卡尔树本质上是静态的 Treap**——其中优先级由数组元素值给定，而非随机生成。因此，笛卡尔树也常作为理解 Treap 的基础。

### 4.4 优化区间动态规划（DP）

在某些区间 DP 中，若转移方程满足四边形不等式或可分割性，笛卡尔树可将 O(n^3) 优化至 O(n^2) 甚至 O(n log n)。

---

## 5. 复杂度与优点

| 操作 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 构建 | O(n)       | O(n)       |
| 查询 LCA（RMQ） | O(log n) ~ O(1) | O(n log n) 预处理 |
| 遍历求矩形面积 | O(n) | O(n) |

**优点**：
- 构建极快，无排序或平衡树调整开销。
- 结构静态，易于与 LCA 算法结合。
- 天然反映数组的区间最值信息，便于解决多种范围问题。

---

## 6. 注意事项

- **元素重复**：若值相同，需自定义比较规则（如下标），否则树不唯一。通常可将下标作为第二关键字，构建时用 `(value, index)` 比较。
- **栈的实现**：使用数组模拟栈效率更高，避免动态内存开销。
- **方向**：可根据需要构建大根堆（只需将比较符号反向即可）。

---

## 7. 总结一句话

> **笛卡尔树是数组的“区间最值骨架”，每个节点即其管辖子数组的最值，构建快速，应用广泛。**

掌握它，你将在处理区间查询、矩形面积、以及部分动态规划问题时获得“降维打击”的能力。
