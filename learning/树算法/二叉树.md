# 二叉树

**二叉树**是计算机科学中最基础且最重要的非线性数据结构之一。它本质上是一个层次化的集合，要么为空，要么由一个**根节点**和两棵互不相交的、分别称为**左子树**和**右子树**的二叉树组成（递归定义）。

为了让你快速建立清晰的知识框架，我从五个核心维度来介绍：

### 1. 核心术语与形态
理解二叉树，先要掌握几个基本概念：

- **节点关系**：根节点（最顶层）、父节点、子节点（左/右）、兄弟节点、叶子节点（没有子节点的末端节点）。
- **深度与高度**：根节点的深度为 1（或0，视定义而异），从根向下延伸的层数。
- **独特的“度”**：二叉树最大的特点是**每个节点的度最大为 2**（即最多有两个分叉），并且**左右子树是有序的**（即使只有一棵子树，也必须区分是左还是右）。

### 2. 五种基本形态
根据节点分布和层级的填充情况，二叉树主要有以下几种特殊形态：

- **满二叉树（Perfect Binary Tree）**：所有内部节点都有两个子节点，且所有叶子节点都在同一层（形状完美对称）。
- **完全二叉树（Complete Binary Tree）**：除最后一层外，其余层全部填满，且最后一层的叶子节点**靠左连续**排列（堆排序的底层结构就是完全二叉树）。
- **完满二叉树（Full/Strict Binary Tree）**：每个节点要么是叶子，要么正好有两个子节点（不要求层数全满）。
- **二叉搜索树（BST）**：左子树上所有节点的值均小于根节点，右子树均大于根节点（支持高效的动态查找）。
- **平衡二叉树（AVL / 红黑树）**：左右子树的高度差不超过 1（或满足特定平衡条件），防止树退化为链表。

### 3. 四种遍历方式（核心操作）
遍历是访问树中所有节点的唯一方法，根据**根节点**的访问时机分为深度优先（DFS）和广度优先（BFS）：

| 遍历方式 | 访问顺序 | 核心用途 |
| :--- | :--- | :--- |
| **前序遍历（Pre-order）** | 根 → 左 → 右 | 复制整棵树，或用于导出表达式的前缀表示法。 |
| **中序遍历（In-order）** | 左 → 根 → 右 | 在**二叉搜索树**中，此顺序得到的是一个**升序序列**。 |
| **后序遍历（Post-order）** | 左 → 右 → 根 | 删除整棵树（先删子节点再删根），或计算目录大小。 |
| **层序遍历（Level-order）** | 从上到下、从左到右逐层访问 | 使用队列实现，用于寻找最短路径或连通性判断。 |

### 4. 关键数学性质（面试与算法基础）
- **性质1**：在任意非空二叉树中，**叶子节点数 = 度为2的节点数 + 1**（即 N0 = N2 + 1）。
- **性质2**：第 i 层最多有 **2^(i-1)** 个节点（根节点i=1）。
- **性质3**：高度为 h 的二叉树最多有 **2^h - 1** 个节点。
- **性质4**：具有 n 个节点的完全二叉树深度为 **⌊log₂(n)⌋ + 1**。

### 5. 存储方式与实战应用
- **存储**：链式存储（左右指针）最常用；也可用数组存储（尤其适合完全二叉树，通过下标 `2i` 和 `2i+1` 定位子节点）。
- **现实应用**：
  - **数据库与文件系统**：B树、红黑树用于加速索引查找。
  - **编译原理**：**抽象语法树（AST）** 用于解析代码。
  - **数据压缩**：哈夫曼树（最优二叉树）用于文件压缩（如 ZIP）。
  - **AI与机器学习**：决策树、随机森林模型。
  - **网络路由**：用于构建路由器中的最长前缀匹配表。
