# 树状数组 (Fenwick Tree) 完全指南

## 1. 概述

**树状数组**（英文：**Binary Indexed Tree**，简称 **BIT**），以其发明者命名为**芬威克树**（**Fenwick Tree**）。它是一种用于**高效维护数组前缀和**的数据结构，能够在 **O(log n)** 的时间复杂度内完成**单点更新**和**区间查询**两大核心操作。

该数据结构由 Peter M. Fenwick 于1994年在期刊《Software Practice and Experience》上发表的论文《A New Data Structure for Cumulative Frequency Tables》中首次提出。其设计初衷是解决数据压缩中的**累积频率（Cumulative Frequency）** 计算问题，后来被广泛应用于信息学竞赛和算法工程中，如逆序数计算等场景。

> **注意**：“树状数组”和“Fenwick 树”是**完全等价**的概念，前者是中文社区的习惯叫法，后者是学术界的标准命名。

---

## 2. 核心思想：二进制分解与 Lowbit

树状数组的精髓在于利用整数的**二进制表示**来组织数据。其基本思想是：**正如所有整数都可以表示为2的幂之和，一个序列的前缀和也可以拆解为若干个子序列的和**。

### 2.1 Lowbit 函数

树状数组的核心是 **`lowbit(x)`** 函数，它返回整数 `x` 的二进制表示中**最低位的1所代表的数值**。

```
lowbit(x) = x & (-x)
```

| x | 二进制 | lowbit(x) | 含义 |
|---|---|---|---|
| 6 | 110₂ | 2 | 最低位的1在2¹位 |
| 12 | 1100₂ | 4 | 最低位的1在2²位 |
| 8 | 1000₂ | 8 | 最低位的1在2³位 |



### 2.2 管辖区间

在树状数组中，每个节点 `tree[i]` **并不只存储 `arr[i]` 本身**，而是存储**以 `i` 结尾、长度为 `lowbit(i)` 的区间和**：

```
tree[i] = sum(arr[i - lowbit(i) + 1] ... arr[i])
```

例如（n=8时）：
- `tree[1]` 管辖 `arr[1]`（长度1）
- `tree[2]` 管辖 `arr[1]` + `arr[2]`（长度2）
- `tree[4]` 管辖 `arr[1]` 到 `arr[4]`（长度4）
- `tree[6]` 管辖 `arr[5]` + `arr[6]`（长度2）
- `tree[8]` 管辖 `arr[1]` 到 `arr[8]`（长度8）

## 3. 两大核心操作

树状数组使用 **1-based 索引**（下标从1开始）。

### 3.1 单点更新 (Add)

当 `arr[x]` 增加 `delta` 时，需要更新所有**管辖范围包含 `x`** 的 `tree` 节点。规律是：**不断加上自身的 `lowbit`**，直到超过数组大小 `n`。

```cpp
void add(int x, int delta) {
    for (int i = x; i <= n; i += lowbit(i)) {
        tree[i] += delta;
    }
}
```



**更新示例**：更新 `arr[3]`，需要更新 `tree[3]` → `tree[4]` → `tree[8]`。这些节点的管辖范围都覆盖了下标3。

### 3.2 前缀查询 (Query)

查询前 `x` 个元素的和（即 `arr[1]` 到 `arr[x]`）。规律是：**不断减去自身的 `lowbit`**，直到变为0。

```cpp
int query(int x) {
    int res = 0;
    for (int i = x; i > 0; i -= lowbit(i)) {
        res += tree[i];
    }
    return res;
}
```



**查询示例**：求 `sum(7)`（前7个元素和）：
`res = tree[7] + tree[6] + tree[4]` = `arr[7]` + `(arr[5]+arr[6])` + `(arr[1]+arr[2]+arr[3]+arr[4])` ✅

### 3.3 区间查询

利用前缀和作差，可快速求任意区间 `[l, r]` 的和：

```cpp
int range_query(int l, int r) {
    return query(r) - query(l - 1);
}
```

## 4. 进阶用法

### 4.1 区间更新 + 单点查询

利用**差分数组**的思想，将区间更新转化为两次单点更新：

- 对区间 `[l, r]` 每个数增加 `k`：`add(l, k)`，`add(r+1, -k)`
- 查询 `arr[x]` 的值：`query(x)`

### 4.2 区间更新 + 区间查询

维护**两个树状数组**实现区间加法和区间求和：

- `tree1` 维护差分数组 `diff[i]`
- `tree2` 维护 `diff[i] * (i-1)`

区间和公式：
```
sum(x) = x * Σdiff[i] - Σ(diff[i] * (i-1))
```

### 4.3 二维树状数组

将树状数组扩展到二维，支持**矩阵的单点更新和子矩阵求和**，时间复杂度为 O(log² n)。

## 5. 经典应用场景

| 应用场景 | 说明 |
|---|---|
| **动态前缀和** | 数组频繁变化，需快速查询前缀和 |
| **求逆序对** | 配合离散化，统计数组中逆序对的数量 |
| **维护排名/第K小** | 在值域树状数组上二分查找 |
| **二维偏序问题** | 如统计“小于某个值的元素个数” |
| **区间统计** | 如统计区间内不同元素的个数 |

---

## 6. 优缺点分析

| 维度 | 评价 |
|---|---|
| **代码极简** | 核心仅需5-10行代码，远少于线段树 |
| **时空高效** | 空间 O(n)，常数极小，运行速度极快 |
| **支持操作有限** | 原生仅支持**单点更新 + 前缀查询** |
| **运算需满足可逆性** | 维护的信息必须满足**结合律**且**可差分**（如加法、异或）。**不支持**区间最大值/最小值等不可逆运算 |
| **不易动态修改** | 不支持动态插入或删除元素 |

---

## 7. 与线段树的对比

树状数组和线段树是解决区间问题的“亲兄弟”，但各有侧重：

| 对比项 | 树状数组 (Fenwick Tree) | 线段树 (Segment Tree) |
|---|---|---|
| **代码量** | 极短（~10行） | 较长（~50行） |
| **时间复杂度** | O(log n) | O(log n) |
| **空间复杂度** | O(n) | O(4n) |
| **支持操作** | 较单一（前缀和、异或等） | 极丰富（最值、翻转、赋值等） |
| **实现难度** | 简单 | 相对复杂 |
| **适用场景** | 一维区间和问题 | 复杂多维区间问题 |

> **核心结论**：**树状数组能解决的问题，线段树一定能解决；但线段树能解决的问题，树状数组不一定能解决**。然而，树状数组的**代码简洁性和运行效率**使其在合适的场景下成为不二之选。

## 8. 完整代码模板（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int tree[MAXN], n;

int lowbit(int x) {
    return x & (-x);
}

// 单点更新：将 arr[x] 增加 delta
void add(int x, int delta) {
    for (int i = x; i <= n; i += lowbit(i)) {
        tree[i] += delta;
    }
}

// 前缀查询：求 arr[1] + ... + arr[x]
int query(int x) {
    int res = 0;
    for (int i = x; i > 0; i -= lowbit(i)) {
        res += tree[i];
    }
    return res;
}

// 区间查询：求 arr[l] + ... + arr[r]
int range_query(int l, int r) {
    return query(r) - query(l - 1);
}
```



---

## 9. 总结

**树状数组是线段树的轻量级特化版本**。当问题只需要处理**前缀可逆聚合（和、异或）** 且**数据静态（无插入删除）** 时，树状数组是最佳选择——它足够优雅，足够快，且几乎不可能写错。如果涉及区间最大值、区间翻转等复杂需求，则需升级为线段树。
