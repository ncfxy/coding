# 差分数组

差分数组可以理解为一个**预处理工具**，它的核心用途是：**对原数组的某个连续区间进行频繁的批量加减操作时，能将时间复杂度从 O(n) 降低到 O(1)**。

---

### 1. 从“前缀和”说起（便于理解）

- **前缀和**：将“原数组”通过累加，变成“前缀和数组”。作用是快速求任意区间的和。
- **差分数组**：可以看作是“前缀和”的逆运算。它将“原数组”通过相邻元素的差值，变成“差分数组”。作用是快速对任意区间进行加减操作。

---

### 2. 差分数组的定义

假设我们有一个原数组 `arr`，长度为 n，通常索引从 0 开始：

`arr = [a1, a2, a3, ..., an]`

我们构造一个差分数组 `diff`，长度比原数组多 1（方便处理边界），定义如下：

- `diff[0] = arr[0]`
- `diff[i] = arr[i] - arr[i-1]` （对于 i > 0）
- 为了方便，我们通常设置 `diff[n] = 0`（或 -arr[n-1]）

**关键性质**：对差分数组 `diff` 求**前缀和**，就能还原出原数组 `arr`。

---

### 3. 差分数组的核心操作：区间修改

假设我们要对原数组 `arr` 的区间 **[L, R]**（闭区间）内的所有元素统一加上一个值 `val`。

如果直接操作原数组，需要遍历 L 到 R，时间复杂度 O(n)。

**使用差分数组，只需要两步 O(1) 操作：**

1. `diff[L] += val`
2. `diff[R+1] -= val` （如果 R+1 在数组范围内）

**为什么这样有效？**

- `diff[L] += val` 意味着：从 L 开始，前缀和会多出 `val`，一直传递下去。
- `diff[R+1] -= val` 意味着：从 R+1 开始，前面多出的 `val` 被抵消掉，前缀和恢复正常。
- 这样，只有区间 [L, R] 内的前缀和受到了 `+val` 的影响。

---

### 4. 一个直观的例子

**场景**：有一个长度为 5 的数组，初始全为 0。  
`arr = [0, 0, 0, 0, 0]`

**操作**：将区间 [1, 3] 的所有元素加 10。

- 构造差分数组（初始）：`diff = [0, 0, 0, 0, 0, 0]`（长度 6，多一个边界）
- 执行：
  - `diff[1] += 10`  → `diff = [0, 10, 0, 0, 0, 0]`
  - `diff[4] -= 10`  → `diff = [0, 10, 0, 0, -10, 0]`（索引4对应原数组第4个位置，因为区间结束是3，所以R+1=4）

**还原原数组**（对 diff 求前缀和）：

- 位置0：前0项和 = 0
- 位置1：前1项和 = 0+10 = 10
- 位置2：前2项和 = 0+10+0 = 10
- 位置3：前3项和 = 0+10+0+0 = 10
- 位置4：前4项和 = 0+10+0+0-10 = 0

结果：`arr = [0, 10, 10, 10, 0]`，符合预期。

---

### 5. 多次操作后一次性还原

差分数组最经典的应用场景是：**有多次区间修改操作，最后只需要输出最终数组**。

流程：
1. 初始化差分数组（全0或基于原数组）。
2. 对每次区间修改，只做两次 O(1) 的差分更新。
3. 所有操作完成后，对差分数组求一次前缀和，得到最终数组。

时间复杂度：O(m + n)，其中 m 是操作次数，n 是数组长度。远优于 O(m*n)。

---

### 6. 变体：基于已有数组构建差分数组

如果你的原数组一开始不是全 0，比如 `arr = [2, 5, 3, 8]`，构建差分数组：

- `diff[0] = arr[0] = 2`
- `diff[1] = arr[1] - arr[0] = 5-2 = 3`
- `diff[2] = arr[2] - arr[1] = 3-5 = -2`
- `diff[3] = arr[3] - arr[2] = 8-3 = 5`
- `diff[4] = -arr[3] = -8`（或0，取决于实现）

所以 `diff = [2, 3, -2, 5, -8]`

之后区间修改同样操作在 `diff` 上，最后再求前缀和还原即可。

---

### 7. 适用场景总结

| 场景 | 是否适合差分数组 |
| :--- | :--- |
| 多次区间增减，最后查询一次 | ✅ 非常适合 |
| 多次区间增减，过程中频繁查询单点值 | ✅ 适合（单点查询 = 求前缀和，O(1)） |
| 多次区间增减，过程中频繁查询区间和 | ❌ 不适合（此时应使用线段树或树状数组） |
| 区间修改为固定值（不是加减） | ❌ 不适合（差分只支持加减） |

---

### 8. 代码示例（Python）

```python
def apply_operations(n, operations):
    # n: 数组长度
    diff = [0] * (n + 1)  # 多一个位置处理边界
    
    # 执行所有区间加操作
    for L, R, val in operations:
        diff[L] += val
        diff[R + 1] -= val
    
    # 还原最终数组
    arr = [0] * n
    curr = 0
    for i in range(n):
        curr += diff[i]
        arr[i] = curr
    return arr

# 示例：长度为5，两次操作
ops = [(1, 3, 10), (2, 4, 5)]
result = apply_operations(5, ops)
print(result)  # 输出: [0, 10, 15, 15, 5]
```

---

### 9. 二维差分（扩展）

在二维矩阵中，如果需要对某个子矩阵统一加减，可以用**二维差分数组**，操作变为 4 个点的更新（左上、右上、左下、右下），还原时求二维前缀和。原理与一维类似，是差分思想的推广。
