# 树状数组

**树状数组（Binary Indexed Tree, BIT）**，也称**Fenwick树**，是一种高效且实现简洁的数据结构。它非常适合用来解决**数组的单点更新和区间求和**问题，这两个操作的时间复杂度都能达到 **O(log n)**。

你可以把它看作是**线段树的“轻量版”**：它解决的问题，线段树都能解决，但树状数组的代码量要少得多，运行效率也更高。

### 💡 核心思想：二进制的魔力

树状数组的精妙之处，在于巧妙地利用了**整数的二进制分解**。

*   **设计灵感**：任何整数都可以表示为若干个2的幂次之和。树状数组也采用了类似的思想，将一个长的序列（比如前缀和）拆解成一系列长度也为2的幂次的子序列，分别进行维护。
*   **关键函数 `lowbit(x)`**：这是理解树状数组的钥匙。`lowbit(x)` 返回的是 `x` 的二进制表示中，**最低位的1所对应的数值**。在代码中，它通过一个极妙的位运算实现：
    ```cpp
    int lowbit(int x) {
        return x & -x;
    }
    ```
    例如：
    *   `lowbit(6)`：6的二进制是`110`，最低位的1代表数值`2`（二进制`10`），所以结果是2。
    *   `lowbit(8)`：8的二进制是`1000`，结果是8。

### ⚙️ 两大核心操作

树状数组用数组 `tree[]` 来存储。`tree[i]` 这个元素，负责维护原数组中以 `i` 为右端点、长度为 `lowbit(i)` 的一段区间的信息（如区间和）。

1.  **单点更新 (Add)**：当原数组第 `i` 个元素增加 `delta` 时，需要更新所有能“覆盖”到位置 `i` 的 `tree` 节点。这些节点的下标可以通过 `i += lowbit(i)` 一路向上查找得到。
    ```cpp
    void add(int i, int delta) {
        while (i <= n) {
            tree[i] += delta;
            i += lowbit(i);
        }
    }
    ```

2.  **前缀和查询 (Sum)**：要计算原数组前 `i` 个元素的和，需要把相关的 `tree` 节点累加起来。这些节点的下标可以通过 `i -= lowbit(i)` 逐步向前查找得到。
    ```cpp
    int sum(int i) {
        int res = 0;
        while (i > 0) {
            res += tree[i];
            i -= lowbit(i);
        }
        return res;
    }
    ```

因此，要查询区间 `[l, r]` 的和，只需要计算 `sum(r) - sum(l-1)` 即可。

### 🎯 主要应用场景

树状数组在算法竞赛和工程实践中应用广泛，主要包括：

*   **求解逆序对**：将数组元素作为“位置”插入树状数组，可以高效地统计每个数前面有多少个比它大的数。
*   **动态维护前缀和**：在需要频繁修改元素值并查询前缀和的场景中非常实用。
*   **处理二维问题**：可以扩展为二维树状数组，用于快速计算子矩阵的和。
*   **结合差分数组**：通过维护差分数组，树状数组也能支持**区间修改、单点查询**，甚至**区间修改、区间查询**等更复杂的操作。

### ⚖️ 树状数组 vs. 线段树

| 特性 | 树状数组 (BIT) | 线段树 (Segment Tree) |
| :--- | :--- | :--- |
| **代码量** | **极少**，核心操作仅几行循环 | 较多，通常需要结构体和递归/非递归实现 |
| **时间复杂度** | O(log n)，常数小，速度快 | O(log n)，常数相对较大 |
| **适用问题** | **局限于**满足**结合律**和**可差分**的问题（如求和、异或） | **极其广泛**，可解决区间最值、区间GCD等几乎所有区间问题 |
| **空间复杂度** | O(n)，一个数组即可 | O(4n) 或 O(2n)，需要额外空间存储树结构 |

### 💎 总结

树状数组是一个**用数组实现的树形逻辑结构**。它通过二进制的 `lowbit` 操作，用极简的代码实现了高效的动态区间求和。

**一句话总结**：如果你的问题核心是**单点更新+区间求和**，且维护的信息满足**可加性和可减性**，那么树状数组是你的不二之选。如果问题更复杂（如区间最值），则需要考虑功能更强大的线段树。
