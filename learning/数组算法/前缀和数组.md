# 前缀和数组
前缀和数组是一种非常实用的**空间换时间**技巧，核心思想是：**把一个数组前 \(i\) 个元素的累加和提前存好，从而将任意区间求和的时间从 \(O(n)\) 降为 \(O(1)\)**。

---

### 1. 它是什么？
给定原数组 `nums`（假设长度为 \(n\)），它的**前缀和数组** `pre` 满足：
> `pre[i]` = `nums[0] + nums[1] + ... + nums[i]`

这样，你想计算任意区间 `[L, R]` 的和，只需要：
> 区间和 = `pre[R] - pre[L-1]` （当 \(L > 0\) 时）
> 如果 \(L = 0\)，区间和直接就是 `pre[R]`

### 2. 常见的实现技巧
为了方便处理 \(L=0\) 的边界，通常会让前缀和数组长度比原数组**多 1**，定义：
- `pre[0] = 0`
- `pre[i+1] = pre[i] + nums[i]` （\(i\) 从 0 开始）

这样，区间 `[L, R]` 的和永远是：
> `sum(L, R) = pre[R+1] - pre[L]`

**例子：**  
`nums = [2, 3, 5, 1, 4]`  
构建过程：
```
pre[0] = 0
pre[1] = 0 + 2 = 2
pre[2] = 2 + 3 = 5
pre[3] = 5 + 5 = 10
pre[4] = 10 + 1 = 11
pre[5] = 11 + 4 = 15
```
得到 `pre = [0, 2, 5, 10, 11, 15]`

现在计算索引 1 到 3（元素 `[3,5,1]`）的和：
`sum = pre[4] - pre[1] = 11 - 2 = 9` ✅

### 3. 复杂度分析
- **构造前缀和数组**：一遍扫描，\(O(n)\)
- **单次区间查询**：直接减法，\(O(1)\)
- **空间开销**：额外 \(O(n)\)（很多时候可以原地覆盖，但通常保留原数组更方便）

### 4. 什么时候用它？
最典型的场景是：**需要多次查询某个数组的区间和**，比如：
- 多次求子数组的最大和、平均值
- 作为更复杂算法（如哈希表 + 前缀和解“和为 K 的子数组”）
- 处理环形数组区间和（通过复制一份数组，再用前缀和）
- 计算二维矩阵的子矩阵和（二维前缀和）

### 5. 二维前缀和（简单提一下）
二维前缀和可以 \(O(1)\) 求出矩阵任意子矩阵的和。  
构建公式：`pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + matrix[i][j]`  
查询以 `(r1,c1)` 到 `(r2,c2)` 为对角的子矩阵和：
`sum = pre[r2][c2] - pre[r1-1][c2] - pre[r2][c1-1] + pre[r1-1][c1-1]`

### 6. 小提醒
- 前缀和很容易**整数溢出**，如果数字很大，记得用 `long long` 或类似大类型。
- 前缀和数组本身只适用于**静态数组**（数组不变）；如果经常修改元素的值，就需要改用**树状数组（Fenwick Tree）或线段树**。

---

**总结一句话：**  
前缀和数组就是“先把累加结果记下来，要用的时候直接取差值”，把反复的加法运算变成一次减法运算，极大提高区间求和的效率。
