# 模逆元求解完全指南

在模运算中，若存在整数 $x$ 使得 $a \times x \equiv 1 \pmod{p}$，则称 $x$ 为 $a$ 关于模 $p$ 的**模逆元**，记作 $a^{-1}$。**逆元存在的充要条件是 $\gcd(a, p) = 1$**（即互质）。

本文总结了竞赛编程和密码学中四种最常用的求逆元方法。

---

## 方法一：费马小定理（快速幂）
**适用场景**：模数 $p$ 为**质数**，且 $a$ 不是 $p$ 的倍数。  
**时间复杂度**：$O(\log p)$

**原理**：由费马小定理 $a^{p-1} \equiv 1 \pmod{p}$ 得：
$$
a^{-1} \equiv a^{p-2} \pmod{p}
$$

**代码实现（Python）**：
```python
def mod_pow(base, exp, mod):
    res = 1
    while exp > 0:
        if exp & 1:
            res = res * base % mod
        base = base * base % mod
        exp >>= 1
    return res

def inv_fermat(a, p):
    # 前提：p为质数，且 a % p != 0
    return mod_pow(a, p - 2, p)
```

---

## 方法二：扩展欧几里得算法
**适用场景**：任意模数 $p$（**不要求质数**），只需 $\gcd(a, p) = 1$。  
**时间复杂度**：$O(\log p)$

**原理**：求解同余方程 $a \times x + p \times y = 1$ 中的 $x$。

**代码实现（Python）**：
```python
def exgcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x1, y1 = exgcd(b, a % b)
    return g, y1, x1 - (a // b) * y1

def inv_exgcd(a, p):
    g, x, _ = exgcd(a, p)
    if g != 1:
        return -1  # 逆元不存在
    return x % p
```

---

## 方法三：线性递推求 1 到 n 的所有逆元
**适用场景**：模数 $p$ 为**质数**，需要一次性预处理 $1$ 到 $n$（$n < p$）所有整数的逆元。  
**时间复杂度**：$O(n)$

**核心公式**（设 $inv[1] = 1$）：
$$
inv[i] = (p - \lfloor \frac{p}{i} \rfloor) \times inv[p \bmod i] \bmod p
$$

**代码实现（C++）**：
```cpp
const int MOD = 1e9 + 7;
long long inv[MAXN];
inv[1] = 1;
for (int i = 2; i < MAXN; i++) {
    inv[i] = (MOD - MOD / i) * inv[MOD % i] % MOD;
}
```
**注意**：$i$ 必须小于 $p$，且 $p$ 必须为质数。

## 方法四：阶乘逆元递推（组合数预处理）
**适用场景**：频繁计算组合数 $C(n, k)$。  
**时间复杂度**：预处理 $O(n)$，单次查询 $O(1)$

**操作流程**：

1. **正推阶乘**：
   $$
   fact[i] = fact[i-1] \times i \bmod MOD
   $$

2. **仅用一次快速幂**求最大阶乘的逆元：
   $$
   inv\_fact[n] = fast\_pow(fact[n], MOD - 2)
   $$

3. **倒推得到所有阶乘逆元**（关键递推公式）：
   $$
   inv\_fact[i-1] = inv\_fact[i] \times i \bmod MOD
   $$

**为何成立**？  
因为 $fact[i] = fact[i-1] \times i$，取逆元后移项即得：
$$
\frac{1}{(i-1)!} = \frac{1}{i!} \times i
$$

**组合数查询**：
$$
C(n, k) = fact[n] \times inv\_fact[k] \times inv\_fact[n-k] \bmod MOD
$$

**代码示例（Python）**：
```python
MOD = 10**9 + 7
n = 100000
fact = [1] * (n + 1)
for i in range(1, n + 1):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * (n + 1)
inv_fact[n] = pow(fact[n], MOD - 2, MOD)  # 费马小定理求逆元
for i in range(n, 0, -1):
    inv_fact[i-1] = inv_fact[i] * i % MOD
```

## 总结对比：该如何选择？

| 方法 | 模数要求 | 预处理/单次 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **费马小定理** | 必须为质数 | 单次 $O(\log p)$ | 模数为 $10^9+7$ 等固定质数，求单个逆元 |
| **扩展欧几里得** | **任意**（只需互质） | 单次 $O(\log p)$ | 模数未知或是合数时（如题目模数非质数） |
| **线性递推** | 必须为质数 | 批量 $O(n)$ | 需要 1 到 n 所有数的逆元（如分母累乘） |
| **阶乘递推** | 必须为质数 | 批量 $O(n)$ + 查询 $O(1)$ | **专门用于预处理组合数**，效率最高 |

---

## 避坑警示

1. **互质检查**：无论用哪种方法，如果 $a$ 是模数 $p$ 的倍数，逆元**不存在**。
2. **质数限制**：费马小定理和两个递推公式都严格依赖模数为质数，若误用于合数（如 $p = 10$），结果完全错误。
3. **数组越界**：在线性递推中，$i$ 必须小于 $p$，否则 $p \bmod i$ 可能大于 $i$，导致递推依赖未初始化的值。
